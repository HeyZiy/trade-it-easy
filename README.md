# trade-it-easy

个人 A 股交易策略系统：策略研究、信号生产、尾盘执行与名义台账记账一体化。

## 策略地图

| 策略          | 入口                                                   |
| ----------- | ---------------------------------------------------- |
| 多资产配置    | 投资看板（持仓与目标配比）                         |
| 跨资产动量  | `etf_rotation.py`                                    |
| 质量动量       | `quality_pool.py`（09:30 生成建议与报告） |
| 价格循环（Cycle） | —                                                    |


各策略的定位、假设与不可混用边界见 [strategy/overview.md](strategy/overview.md)。

## 运行环境

- Python 3.14
- 依赖：`pip install -r requirements.txt`
- 敏感配置：`.env`（含数据源 token / 邮件 / 推送密钥）

## 部署（云服务器）

`deploy/crontab.server`：质量动量 09:30（昨收信号与实际账户建议）→ 市场观察周报 14:40（周一）→ 跨资产动量 14:50。质量动量规则见[质量池规格](strategy/quality_pool.md)。

## 投资账户与成绩

日报顶部展示最近完整收盘的累计收益、同期基准、超额收益、运行天数与仓位现金。
多资产配置、跨资产动量、质量动量和债券组合在同一投资账户内分别记录持仓、现金和累计盈亏，实际成交由用户确认记账。场内持仓按看板标注的收盘估值日计价，缺价时可手动刷新。

在「多资产配置」或「债券组合」页签的「编辑配置」中设置该组合的标的权重，以及各策略占账户总资产的目标比例。组合内未分配给标的的权重自动计为目标现金。通过「划转现金」或「分配现金」为策略拨款。

在看板「编辑配置」中可按账户设置股票和 ETF 的佣金率及最低佣金，以及 A 股卖出印花税率。录入成交时自动计算费用，也可按交割单填写实际手续费。

可在看板「编辑配置」中设置投资账户的场外基金统一申购费。账户未设置统一费用时，沿用各基金上次登记的费用。场外申购、赎回和定投均归所属组合记账，两个组合可以持有同一只基金。申购先从所属组合扣款并计入在途资产，取得买入日公布的单位净值后按实际扣款和申购费确认份额。

`deploy/crontab.server` 在工作日北京时间次日08:30采集上一交易日收盘成绩，给ETF日线源留出整夜，
并回补最近5个交易日的不完整记录；更新服务器代码后需重新安装该定时任务表。仍缺价时保留最近完整成绩。
收盘任务不交易、不发送通知，成绩与台账保存在服务器，本地不会自动同步。

```bash
python portfolio_report.py                  # 采集最近已收盘交易日，并回补前5个交易日缺口
python portfolio_report.py --dry-run        # 只展示，不保存
python portfolio_report.py --date 2026-10-09 # 重试或补采指定已收盘交易日（只采该日）
```

基准与存储口径见 [src/trade_ledger/performance.py](src/trade_ledger/performance.py) 与 [ledger.py](src/trade_ledger/ledger.py)。
