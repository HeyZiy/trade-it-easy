# 数据文件清单（data manifest）

> data/ 及相关运行数据的类别与同步方向清单，与 `deploy/crontab.server` 同为部署真源。
> 服务器是在产写入者；本地 data/ 只在服务器不可用时才当离线分支。
> 文件改动时同步更新本表。恢复时的使用方式（diff 起手、超集/完整度合并、备份、md5 归零）
> 见 skill `trade-it-easy-deploy` 的「数据同步拓扑」节。

## 类别与同步方向

| 类别 | 含义                         | 方向                 |
| -- | -------------------------- | ------------------ |
| 配置 | 人工/看板改动产生，代码读它             | 本地 → 服务器（本地改动要推送）  |
| 账本 | 程序追加的事实，append-only + UUID | 双向合并：验超集/完整度后按新者覆盖 |
| 缓存 | 程序自动重建的派生数据                | 不同步，缺了自动重拉/重算      |
| 归档 | 只读历史记录                     | 服务器 → 本地（快照脚本负责）   |

## data/ 根目录

| 文件                                           | 类别 | 说明                                                                                    |
| -------------------------------------------- | -- | ------------------------------------------------------------------------------------- |
| `etf_account.json`                           | 账本 | 投资账户事件账本（含 dca 定投补记流水）。带 revision + lock                                              |
| `etf_config.json`                            | 配置 | 核心仓 15 品种权重、budgets、trade\_fees、fund\_subscription\_fee。看板可改，历史在 `etf_config.history` |
| `fund_plans.json`                            | 配置 | 场外基金定投计划。账本同目录随账本迁移                                                                   |
| `trade_ledger_*.jsonl`                       | 归档 | 历史名义交易记录，供离线查账                                                                   |
| `etf_config.history`                         | 归档 | etf\_config 每次改动的历史快照，随配置一起推                                                          |
| `.lock` 文件                                   | 缓存 | json\_store 文件锁，不同步、可删                                                                |

服务器侧另有 `*.pre-sync.bak` 类覆盖前备份，确认稳定后可清。

## data/ 子目录

| 路径                        | 类别 | 说明                                                                       |
| ------------------------- | -- | ------------------------------------------------------------------------ |
| `AmazingData_local_data/` | 缓存 | TGW/AmazingData HDF5 本地表（basedata/infodata，60M）。缺表会让 timing 计算挂死，建议随快照带上 |
| `fund_names.sqlite3`      | 缓存 | 基金名称缓存                                                                   |
| `security_names.sqlite3`  | 缓存 | 证券名称缓存                                                                   |
| `timing_reports/`         | 归档 | ETF 择时研究报告（archive/ 是研究归档，\*.json 是看板生成）                                 |
| `migrations/`             | 归档 | 历史数据迁移记录                                                                 |

## data/ 外的运行数据

| 路径          | 类别 | 方向       | 说明                                                                              |
| ----------- | -- | -------- | ------------------------------------------------------------------------------- |
| `.env`（仓库根） | 配置 | 本地 → 服务器 | 密钥/凭证。上传后 `sed -i 's/\r$//'` + `chmod 600`。两边可能漂移（如 FEISHU\_WEBHOOK\_URL），以最新为准 |
| `reports/`  | 归档 | 服务器 → 本地 | 每日报告 markdown，快照脚本覆盖                                                            |
| `logs/`     | 归档 | 服务器 → 本地 | 运行日志，仅排障用，可不恢复                                                                  |
