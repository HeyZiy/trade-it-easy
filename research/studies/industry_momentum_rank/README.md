# 行业动量排名：预测力能持续多久，25 日窗口合适吗？

本研究先测信号质量。入口只有完整的 `study_jq.py`，直接使用聚宽数据，支持聚宽策略回测编辑器。候选包括境内行业/主题ETF与商品期货ETF，剔除债券。运行时打印进度，结束时打印七个回看窗口的比较，并导出明细。

兼容聚宽旧版 pandas/NumPy：数组转换使用 `.values`，同分排序使用 `mergesort`。启动日志与 `metadata.json` 记录实际库版本。旧版接口核对：[pandas 0.23.4 数组转换](https://github.com/pandas-dev/pandas/blob/v0.23.4/pandas/core/generic.py)、[稳定排序](https://github.com/pandas-dev/pandas/blob/v0.23.4/pandas/core/series.py)。

## 三个不同的问题

1. **当前排名有预测力吗？** 看横截面 Rank IC、三等分收益、高减低、正分候选内 IC，以及前三相对正分候选等权收益。
2. **旧排名多久失效？** 在信号日冻结成员和排名，分别看第 1—5、6—10、11—20、21—40、41—60、61—80 交易日。后续独立区间很重要：0—60 日累计收益包含前 20 日，不能据此认定信号持续有效。
3. **更新排名比保留旧排名好吗？** 第 20 日在原候选集合上重新评分，比较两套排名对第 21—40 日的 IC，以及更新前三相对原前三的收益。另记录原三只在更新时均仍为正分、但排名换名单的事件。

若旧信号衰减，只说明需要重新评估；它不自动证明应换仓。还要看到更新后的信号有增量，以及替代标的随后更好。更新比较采用合成前三信号组，没有模拟中途止损，不能代替原策略实际持仓的换仓回测。

## 固定实验口径

- 扫描回看 L = **10、15、20、25、40、60、120**。每次用 L 根历史收盘加信号日收盘，共 L+1 点；其余公式不变：对数加权回归、年化×w²加权 R²、近三日任一跌幅超过 5% 清零、四位小数。
- v2候选范围在 IM 3.3.2 基础上剔除 `511` 代码段，并保留名称中的“债”及“城投”过滤，防止“城投ETF”等简称漏过。保留有色、能源化工、豆粕等境内商品期货ETF，不再因“商品”或“豆粕”名称剔除。365 日上市年龄、过去 20 日日均成交额 5000 万、过去 250 日收益相关性去重 **0.90、流动性优先**继续用于建池。各 L 使用同一候选集。
- 每 20 个交易日冻结一次，建议回测区间 **2016-01-04 至 2026-09-30**，策略编辑器以界面设置的日期为准。只纳入能走完 80 日观察的信号；各 L、各年龄区间共享相同信号日期与截至信号日完整的 121 点价格样本。早年行业ETF较少，样本不足会明确记录；不因缺测补零或事后删除信号日期。
- 建池只用信号日之前的数据；评分用信号日已完成的收盘。正式理论报价收益为次日开盘到 H 个交易日后开盘；这是收盘因子诊断，区别于原策略 14:55 分钟报价，也不验证开盘可成交性。
- 第 20 日更新时保持原集合，包括后来出池的成员，隔离“更新信号”和“重建池”。未来停牌/缺价不改组、不补零：任一组成员缺价则组收益缺测；IC 用有效配对并报告覆盖率。
- 全池和仅正分候选分别报告；避免把负分剔除的作用误认为正分内部排序的能力。前三并列按冻结池顺序解并列，同时记录切点同分。
- 信号期为统计单位，不把每只 ETF 当独立样本；报告 Newey–West 均值 t，滞后至少 3 轮并覆盖观察区间重叠。有缺失期不压缩时间轴计算 HAC，t 标记缺测。条件换名单事件可能不连续，因此不要用其均值单独声称显著。
- 各 L 的原始共同样本一致，但正分足够三只、未来报价完整等条件会让不同指标的有效期数不同，均值比较须核对 n。策略编辑器改 `PHASE = 10`、Notebook 用 `--phase 10`，可复核另一组20日网格，不按结果挑起点。
- 2016—2019、2020—2023、2024—2025、2026 为描述性时间分段。此前已有分析看过这些数据，**不宣称未见留出验证**。25 为既有基线，其他 L 为探索扫描；不自动选择最高值、不自动修改生产参数。后续应确认相邻参数是否稳定，并锁定规则等待新数据验证。
- t 值是未作多重扫描校正的描述统计，不把某一个参数/区间的显著值单独作为裁决。

## 运行

**聚宽策略回测编辑器（主要入口）**：

1. 把完整的 `study_jq.py` 复制进编辑器。
2. 在界面设置回测日期，建议 **2016-01-04 至 2026-09-30**，日频即可。文件里的 `START/END` 只用于 Notebook；改文件不会自动改变策略回测日期。日志会显示实际起点及结束时的实际区间。
3. 点击运行。启动时日志立即出现 **`[排名诊断启动]`**，每20交易日出现 **`[排名诊断信号]`**。
4. 第一批信号在其后的第81个交易日完成全部观察区间，出现 **`[排名诊断成熟]`**，随后逐批导出明细；回测结束出现 **`[排名预测力对照]`** 和七行 `L=...` 汇总。
5. 在聚宽**投资研究文件区**下载 `industry_momentum_rank_v2_` 前缀的结果，重点看 `industry_momentum_rank_v2_summary.csv`。

实验不下单，回测页面的策略收益曲线会保持零收益；研究结果看**日志和CSV**。至少需要首个信号加后续81个交易日，共82个交易日，以及可读取的251日建池历史。区间不足时结束日志明确说明原因，状态写入 `README.md` 和 `metadata.json`，不会默默结束。

每个信号的池与截至信号日的历史价格在当天收盘后保存；后续报价等80日区间完全成熟后读取，开启 `avoid_future_data`，不提前取未来价格。所有统计区间共享完整成熟信号。

v2使用新前缀保留旧版含债券结果；不同候选范围的结果须分开解释。同一个v2前缀会覆盖前次v2运行，新运行会先清空结果、写入运行状态。复核不同 `PHASE` 时同时修改 `OUTPUT_PREFIX`，保留两组结果。

**聚宽研究 Notebook（可选）**：上传同一文件，在已有聚宽数据接口的 Notebook 执行：

```python
%run -i study_jq.py
```

`-i` 保留 Notebook 中的平台接口。默认日期可改文件开头，或传 `--start` / `--end`；结果保存到脚本旁 `results/joinquant_v2/`。Notebook 会打印结果目录及每批读取进度。

## 看哪些输出

- `README.md`：窗口×预测年龄总览；Notebook 环境有 matplotlib 时另生成 `forecast_heatmap.png` 独立年龄段 IC 热力图。
- `summary.csv`：所有指标、有效期数、HAC、各时间分段。重点先看 L=25 的 0—20 与 20—40，再看 `fresh_ic` / `ic_gain` / `switch_positive_incumbents`，最后比较相邻 L。
- `periods.csv`：逐信号、逐窗口统计；`snapshots.csv`：冻结分数、排名、分组和第 20 日重算分数。
- `returns.csv`：共享的每只 ETF 各区间收益及起止日期；`updates.csv`：新旧名单与收益差；`audit.csv`：各信号原池、共同样本及当时的简称 `pool_names`，用于核对名称过滤。
- `metadata.json`：报价/样本口径、完成状态、成熟信号数；能访问脚本文件时记录 SHA256，策略编辑器无源文件路径时为空。

策略编辑器的这些文件均带 `industry_momentum_rank_v2_` 前缀；Notebook 输出使用上面的短文件名。

收盘后回调与运行时序参考：[JoinQuant 官方平台 API](https://cdn.joinquant.com/help/img/JoinQuantAPI.pdf)。方法不等同经典论文中的月度多空组合；也没有把分组收益包装成真实净值回测。
