# 主动基金周定投与目标止盈轮动

在仓库根目录运行。

```powershell
.\.conda\python.exe -m research.studies.fund_target_rotation.backtest
```

默认读取天天基金净值和申赎状态并缓存到 `research/data/fund_target_rotation/`。也可以通过 `--input 路径` 读取同口径文件，列名为 `date,code,nav,growth,subscription,redemption`。代码保留前导零，growth 为源站披露的日净值涨幅，单位是百分数。

只有日净值时，可使用天天基金 `pingzhongdata` 的每日涨幅及净值，按 `date,nav,growth,code` 保存为每只基金一个 CSV，文件名为六位基金代码。

```powershell
.\.conda\python.exe -m research.studies.fund_target_rotation.backtest --nav-dir research/data/fund_target_rotation/daily_nav --output research/data/fund_target_rotation/equity_pool_results --actual-only
```

该模式假定普通净值日可以申赎，并按易方达公告排除 110011 的已知港股通休市日。各基金临时停申赎与金额限制仍可能影响成交。另输出 `no_qdii` 情景，将 110011 移出可买池但保持原起点。备齐 A 类净值后可去掉 `--actual-only` 一并运行代理组。

- 实际份额组用表中的 9 只 C 类基金与 110011。延长样本的代理组用表中的 10 个原代码。各组在池内所有基金都能按统一窗口排名后起跑。鹏华弘利 A（001122）及 C（001123）因股票仓位较低移出主动权益基金池。
- 初始现金 1 万元，周投 500 元，每周首个国内净值日扣款。用截至前第二个国内净值日的近 60 个国内净值日收益排序。当日暂停申购的基金不进入新一轮候选，持有中遇到暂停申购跳过当周。限大额按可接受当期小额申购处理。
- 止盈信号按上一国内净值日估值，QDII 按前第二个国内净值日估值。净赎回估值达累计本金的 110% 时发出信号，按首个可赎回日净值成交。到账分别按 2 或 7 个国内净值日建模，当期全部定投资金来自原现金与已到账的赎回款。分红按源站日涨幅复利近似再投资。
- A 类与 110011 申购费假设 0.15%。赎回主情景把现行一般费率下限应用于整个样本，持有少于 7 天收 1.5%、7 至 29 天收 1%、30 至 179 天收 0.5%、其余按 0 估算。低费情景在前两个档位分别收 1.5% 和 0.5%，之后收 0。持有天数按交易日期差估算。各基金和时期的实际费率以对应招募说明书和销售渠道为准。[证监会《公开募集证券投资基金销售费用管理规定》](https://www.csrc.gov.cn/csrc/c101954/c7606091/content.shtml)
- 对比同池随机换仓 200 次与等权定投；另查周投降至 250 元、几组起始日期变化，以及代理组从实际份额组起始日开始的表现。现金按零收益计，未卖出份额按期末市值计。

`summary.csv` 保存各次运行的账户收益、最大回撤、换仓次数、最长持仓时间和平均资金使用率。主情景另写账户曲线、轮动明细、随机组曲线的 10/50/90 分位数。以现名单回看历史，只能评估这组基金对轮动规则的适配程度。
