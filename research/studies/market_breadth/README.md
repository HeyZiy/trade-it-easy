# A 股市场观察 · 行业广度

每周按当周最后一个交易日收盘更新。单周观察变化，滚动四周观察多数行业是否持续参与上涨。两个周期均展示 31 个申万一级行业的上涨数、上涨数较上周变化及行业收益中位数，再对照 A500 同期收益及其相对行业中位数的差值。

## 风险提示

过去四周 A500 上涨、上涨行业不超过 15 个时，标记上涨参与面偏窄。过去四周 A500 下跌、至少 16 个行业上涨时，记录反向分化。

后续风险对比限于过去四周 A500 上涨的观察周，比较后续四周的下跌比例、平均收益和最低周收盘相对于观察周收盘的收益。最低收益大于零时，以零计下探。最近四个观察周没有完整的后续四周表现，仍展示在广度图里。样本对照还单独检查上涨行业数比上周减少是否有类似效果。

2025 年起的本地历史里，值得提示的是指数上涨、涨势仍未覆盖多数行业的分化。它适合触发对加仓节奏和已有仓位集中度的人工复核。上涨行业数单纯减少只记为观察项。参与面门槛源自对历史行情的观察，命中集中在少数行情，重叠的四周窗口会重复计算同一段下跌。报告同时提供各个触发周的表现和按后续窗口重叠合并的段数。

## 复跑

在仓库根目录执行：

```bash
.conda/python.exe research/studies/market_breadth/replay.py
```

默认从 2025 年起回放到本地数据覆盖的最后一个完整观察周。支持 `--start`、`--end` 和 `--data-dir`。周末用周五标记，整周休市跳过。

输入与结果保存在 `data/market_breadth/`。`a500.csv` 来自项目的 `get_index_daily('000510')`，`sw_names.csv` 来自 AmazingData 行业基础表，31 份 `*.SI.csv` 来自申万宏源研究行业指数历史接口。

浏览器打开 `a-share-breadth-report.html` 查看现状、时序图和历史风险对比。两套周频明细分别输出为 `weekly_1w.csv` 和 `weekly_4w.csv`。

## 全 A 个股广度探针

将 [stock_breadth_jq.py](stock_breadth_jq.py) 粘贴到聚宽策略回测，使用日频。先用一个季度验证导出和覆盖率，例如 2026-04-01 至 2026-06-30。正式回放建议从 **2010-01-01** 开始，结束日取最近一个完整观察周。若单次回测超时，可按连续年份分段执行，将各段导出的数据行合并并保留一行表头。

脚本每周只在最后一个交易日收盘后采样。股票池为当时仍上市、在四周窗口起点已经上市的沪深京 A 股。仅使用起点和终点均有有效复权收盘价且均未停牌的股票，平盘计入分母。每周输出可比较股票数、上涨数、覆盖率、上涨占比及沪深 300 收盘。日志记录每周覆盖率和取数耗时。

下载聚宽生成的 `a_share_stock_breadth_weekly.csv`，放进本地 `data/market_breadth/` 后执行：

```bash
.conda/python.exe research/studies/market_breadth/analyze_stock_breadth.py data/market_breadth/a_share_stock_breadth_weekly.csv
```

以过去四周沪深 300 上涨为对照条件，按上涨个股占比是否超过一半分组。输出未来四周下跌周数、期末平均收益和最深周收盘下探，并按年代、本周指数是否上涨分层。前四行缺少回看所需的指数收盘，最后四行没有完整未来收益。覆盖率至少 90% 才纳入风险对照，保留被排除的周供诊断。有申万数据重叠时，按同一对起止交易日比较个股广度与行业广度，重点看两种口径给出不同判断的周。窄涨周按未来区间是否重叠统计段数，便于判断结果是否集中于同一轮行情。
