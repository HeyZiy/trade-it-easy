## 当前推荐：回测编辑器单文件版

你的使用方式是聚宽回测编辑器，直接复制 `roe_factor_study_jq.py` 的全部内容即可。
不需要上传其他模块、不需要本地JQData账户；平台数据权限仍以当前账户为准。

回测页面设置区间2016-01-04～2026-09-01；资金对该诊断没有影响，因为脚本不下单。
每20交易日选股，财务/估值和收盘截止T−1，T日14:55固定因子与分组。
T+1日9:31读取已知开盘报价，下一轮T+1日9:31才计算已经发生的区间收益。
首个有效指标要等第一个完整20交易日区间结束；期末未完成区间不纳入。

默认同时分析1日/5日 × 原始/行业-log市值中性化四组，查询共享原候选池的61根收盘。
`PLOT_MODE='spread'` 展示最近完成区间的最高组减最低组收益差，单位百分点；
可改为 `'ic'`、`'groups'`、`'coverage'`、`'off'`。
`'groups'` 会显示20条组收益线，建议只在需要细查时启用。
画线是区间指标，非累计净值；非评价日沿用最近有效值。
缺测不会填0，平台可能继续显示该线旧值，因此覆盖率与最终日志是判断缺测的依据。

最终日志输出每组IC/ICIR、普通与HAC均值t、五组平均收益/有效期数、
高减低差、年度分布、覆盖率、名单换手和筛选请求异常。
页面的策略收益/夏普来自未交易账户，不代表这些分组，请看自定义指标和汇总日志。
不需要导出交易明细，跑完可直接复制日志分析。

脚本使用动态前复权，在退出日重新查询已过去的入场开盘，使其与退出日真实报价对齐，
避免送转除权被误算成大跌。停牌或缺失端点仍标记缺测，不模拟延迟卖出。
开盘报价不等于9:31实际撮合，也未模拟涨跌停买卖限制、成交量、滑点或税费。
本地用模拟数据验证了候选池一致性、逐期时间边界、除权及停牌行为，未运行真实平台回测。

## ROE专用入口：一次测1日、5日（多文件）

在聚宽研究环境上传以下四个文件（放同一目录）：

1. `roe_factor_study.py`（本目录）
2. `single_factor_test.py`（`../../tools/single_factor/`）
3. `roe_pool.py`（本目录）
4. `roe_rotation_v1_1_2.py`（本目录）

运行：

```python
%run roe_factor_study.py
```

默认2016-01-04～2026-09-01，从起始日第一交易日起，每20交易日生成一次信号，
沿用原策略选股时点和完整候选池，输出1日/5日 × 原始/中性化四组诊断。
两种窗口共享候选池、控制变量、未来收益和原策略61根收盘历史，不重复跑两遍。

首次可以缩短区间确认平台接口和数据权限：

```python
from roe_factor_study import main
tables, snapshots = main(start='2016-01-04', end='2017-12-31', plot=False)
```

起始日改变会重新定位“每20交易日”的第一轮，不能把换起点后的结果当作原曲线切片。
输出目录 `roe_factor_output` 包含四份周期表、每轮候选股快照、`pool_audit.csv`、
参数与候选池源文件SHA256记录。无需平台交易明细；实际文件下载权限以平台为准。
只保留完整未来持有窗口，最后一轮可能被排除，因此轮数与策略最终入选统计不必相同。

适配器从v1.1.2源文件加载候选池函数和常量，不执行初始化或交易代码。
财务/估值/收盘截至T−1，ST/停牌和解禁筛选沿用信号日规则；
只读取信号日全天停牌标记，不读取信号日收盘行情，也不读取当前日状态。
原策略历史行情对停牌日填前收盘，ROE入口为对齐基线保留该行为；
独立指数池入口默认不填停牌日，两者不能混称完全相同的预处理。
原策略的PE/PB上界、单季度ROE×4及解禁异常时放行保持不变。
API请求失败导致ST/解禁筛选放行时会警告并记录审计表；缺失信号日停牌状态则停止。
供应商解禁历史公开时点、前复权精度和平台history的实际一致性仍需真实数据抽样核对。

图中的分组曲线一旦缺失便停止，可能不如策略净值完整。
此时优先查看周期收益、覆盖率和异常快照，不为接上曲线而填0。

## 信号层诊断实跑结果（2026-10-04，roe_factor_study_jq.py 平台回填）

区间 2016-01-04~2026-09-01，130 轮，候选均 121.2（最小 2/最大 258），
筛选异常放行 0 次，配对覆盖 99.7%；t_HAC 全部 NA（未出，判读以 t_iid 为准）。

| 组 | IC | ICIR | t_iid | 高减低/期 | 单调性 |
|---|---|---|---|---|---|
| M1_raw | +0.0054 | +0.032 | +0.35 | +0.34pp | 否（G3谷底） |
| M1_neutral | +0.0077 | +0.062 | +0.68 | +0.07pp | 否 |
| M5_raw | +0.0120 | +0.073 | +0.81 | +0.16pp | 否 |
| M5_neutral | +0.0087 | +0.081 | +0.90 | +0.01pp | 否 |

年度符号漂移大：2024 年 M1/M5 IC +0.165/+0.174，2026 迄今 −0.17/−0.075。
**判读：1d/5d 动量在 v1_3 候选池的 20 日窗口上无全池区分力（|t| 全部 <2）。**
策略层 random(+29.4%) ≪ 动量(+85.6%) 的差距在信号层没有对应截面梯度，
剩余候选解释：(a) 头部专属效应（取前10≈top 8%，全池IC看不见）；
(b) 高波动倾斜（涨幅头部≈涨停/高波集中，赚波动放大贝塔）；(c) 小样本运气。
"IC 可能不强而头部有效"由旧警示升级为主要待验假设，验证待做。

同日补跑 **pool_ic_probe_v1.py（Q2+头部检查）**：128 轮，in 组均 121 只、
涨停区均 0.2/最大 5（v1_1 头部不退化，抽签伪影为无池专属）；
Q1 复测 IC +0.0029 / t=+0.16（与上表交叉印证）；
**Q2 准入价值 fwd_in +0.89% vs fwd_out +0.68%，差 +0.20%，t=+0.61 → 池为装饰**。
结论：ROE/单因子族信号层账目结清（无区分+装饰），"池+趋势门"支线
前置未过、判死归档；动量≫random 的 56pp 剩余解释收窄为 (a) 头部凸性、
(b) 高波动集中+复利路径。验 (a) 需在探针 resolve 里加"每轮前10均值−池均值"
差值序列出 t，另起一轮，不追则封存。

## ROE研究下一步（第1项已完成，见上节实跑结果）

1. **先补诊断**：在原策略实际选股日的完整候选池中同时测1日、5日涨幅，
   分别看原始与行业/log市值中性化的IC、五组差异和年份分布。
   （已完成，见上节实跑结果。）
2. **再决定排序**：中性化后仍有效，才支持个股价格强弱；
   中性化后显著弱化，需进一步分别控制行业和市值，不能一概断言是行业动量。
   仅靠年度汇总无法识别真正的收益来源。
3. **独立审计质量筛选**：单季度ROE×4适合原实验对照但不是TTM，
   后续比较持续盈利/多期ROE等口径；改财务口径时不要同时改排序、持仓数和门控。
   ROE降序失败不等于ROE硬筛选无效；筛选贡献需要保留/移除该条件的独立对照。
4. **基础实现问题另开修正版**：核对PE/PB是否须为正、缺失财务/状态筛选的放行逻辑、
   停牌到期退出和现金分配失败原因。修正后先恢复1日排序跑基线，避免混入因子实验。

此轮没有改动ROE交易脚本，也没有预先实施行业中性化交易、财务阈值或趋势门控。

已经看过2016–2026历史结果，因此年度切片只是诊断，不是假装未见过的样本外验证。
