## 当前排名轮动规则

| 环节   | 当前规则                                      |
| ---- | ----------------------------------------- |
| 决策时点 | 每个交易日计划10:40执行                            |
| 价格样本 | 过去25个日线收盘价，加当前价格，共26个价格点                  |
| 动量评分 | 对数价格加权线性回归，权重从1递增至2；分数为 `(exp(250 × slope) − 1) × 加权R²`  |
| 合格候选 | 分数严格大于0、小于5，且通过跌幅过滤                       |
| 跌幅过滤 | 最近三段价格比值中，任一段低于0.95则排除；最近一段包含当前价相对前收盘价的变化 |
| 入场   | 空仓时买入合格候选第一名                              |
| 换仓   | 持仓不再是合格候选第一名时，卖出现持仓并买入新的第一名               |
| 清仓   | 没有合格候选时清仓                                 |
| 继续持有 | 现持仓仍为第一名时不主动调整数量                          |

`np.polyfit`传入的权重为1至2，回归误差和R²采用相应的平方权重。分数中的“年化涨幅”只是25日趋势斜率的换算，用来排名，不是未来一年收益预测。R²描述这段价格路径与拟合趋势的贴合程度，不是盈利概率。

**排名退出是当前实验版本的一部分。** “趋势仍在就继续持有”是另一种退出规则，不能把它当成现有行为。分数上限5与跌幅过滤也都是实际影响进出的规则，它们的独立作用尚未分离。

日内−3%止损、成交量过滤和RSRS过滤均关闭。当前没有固定的单笔亏损止损线、移动止盈线或组合回撤触发线；跌幅过滤不等于账户亏损达到5%就退出。

## 仓位与执行口径

当前目标是单一持仓，建仓或换仓时投入可用现金，预留比例为0，实际仓位受费用、整手与成交情况影响。不按资产波动率缩放仓位，也不根据全池上涨成员占比调整总仓位；持仓不变时，不因价格下跌主动追加买入。

持有创业板、黄金与国债时，资金投入规则相近，承担的风险却不同；当前没有按风险缩放仓位。现有回测将整个回测账户视为该子策略的资金，用于观察它独立运行的表现，不能直接当作总组合表现。

单账户研究脚本没有实现生产总组合的多策略预算与组合再平衡；六账户对照入口使用平台子账户隔离实验资金，两者用途不同。接入总组合时，需要把下单资金限制在分配给它的预算内；降低该子策略占比或调拨资金由组合层决定。历史最大回撤不是未来损失上限。

当前版本属于研究策略，尚未完成实盘执行验证。单账户脚本按目标持仓记持仓天数，未按实际成交后快照核对；卖出失败或部分成交也可能造成实际仓位偏离单一持仓目标。这类执行问题应按事实修复，不能用目标持仓日志代替成交证据。

## 一次回测完成15/37只池的六组对照

入口：[study_pool_controls_jq.py](study_pool_controls_jq.py)。在聚宽新建策略，粘贴整个文件；日期2016-01-01至2026-10-01，初始资金设为**600000元**，频率选“每天”。脚本将资金等分为六个独立子账户，每个10万元，分别运行原15只、混合37只的月度等权、合格持有、排名轮动，不在账户之间划转资金。

辅助图显示六个账户各自的累计收益率，年度及结束日志打印各账户收益率、收益额、期初/期末资产和最大回撤。**平台主图、夏普和总体持仓是六组的合计，不能当作其中某一策略的绩效。** 比较以六条辅助线、分账户日志及导出的每日净值为准。

等权组在每月首个交易日10:40配置当时已上市、历史满25日的成员；暂停成员的目标份额不转给其他成员。合格持有组仅取消“仍合格但排名下降就退出”，分数上限5及跌幅过滤保留；排名组沿用当前25日评分和交易逻辑。同一时点的37只评分只算一次，分别按15/37只名单排序。六组费用均为单边万二、最低5元、零滑点，复权、整手、停牌和实际成交交由平台处理。六组在同一回测中仍可能共同受到平台成交量限制，原15只排名结果应与既有独立账户核对后再合并解释；改变回测频率时六组一起改变，新的分钟结果单独记录。

下载 `pool_control_nav.csv`（每日六组实际净值、现金、市值、持仓及回撤）、`pool_control_signals.csv`（37只决策价格、原始趋势分数、过滤后分数、评分分量、两池排名及暂停状态）、`pool_control_decisions.csv`（交易前实际持仓、目标与退出原因）。退出原因区分排名替换、上限排除、跌幅过滤、非正分和数据缺失；目标不是成交，实际持仓以每日净值文件及平台成交记录为准。文件在新回测初始化时重建；本入口不支持中途热更新后拼接成完整研究区间，需从头重跑。

本轮实际结果已登记，两个排名账户期末净值均与既有独立账户对齐至分位舍入范围内，详见[实验记录](EXPERIMENTS.md)。从仓库根运行 `python research/studies/etf_rotation/analyze_pool_controls.py` 核对三份导出并生成 `results/pool_controls/` 下的汇总、账户指标与逐年结果。

## 其他研究入口与复现

本系列单账户聚宽脚本副图统一显示“单边换手%”与“实际仓位%”，不再重复平台主图的累计收益。单边换手 = 当天实际买卖成交金额之和 ÷（2 × 前次记录的收盘净值）；首日以初始资金为分母，热更新后以重置时净值为分母，不含佣金。无成交为0，首次全仓买入约50%，完整卖出再全仓买入约100%；部分成交按实际数量计算，不按委托金额或目标持仓估算。实际仓位 = 收盘实际持仓市值 ÷ 收盘账户净值，负现金时可能略高于100%。取数失败显示缺失值并记日志，不伪装成0；年度收益和持仓日志继续保留。适用于跨资产版、22行业版、合格持有对照、适配性导出版与旧8只池被动基线；交易规则不变。
