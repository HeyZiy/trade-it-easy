# ETF跨资产趋势轮动

**识别不同资产的上涨趋势，将资金优先配置给相对更强的机会，希望获取趋势延续与资产间强弱切换带来的收益。**

本文先说明策略思路，再记录当前实验。资产池数量、具体ETF、信号公式、回看窗口、持仓数量和交易时点都属于实现选择；当前实验使用15只候选，已有日频回测结果。成员数量不是策略要求。

## 策略思路

### 收益来源：趋势延续与相对强弱切换

收益假设是：不同资产的上涨行情不会完全同步，已经形成的上涨趋势有时会继续。观察多类资产，可以在不同市场阶段寻找机会；识别上涨趋势，是为了参与延续段；比较相对强弱，是为了决定有限资金优先配置给谁。

策略作出两个具体选择：

- **买已经走强的资产：** 用近期上涨速度与价格路径的平稳程度识别趋势，预期这种强势还能延续一段。
- **持续把资金交给领涨者：** 持仓后继续与池内其他资产比较。原持仓即使仍在上涨，只要相对落后到不再进入目标持仓，就让出资金给更强的候选。

我们选择相对强弱轮动作为当前研究主线：持续比较候选，把资金优先交给相对领涨者，而非仅凭持仓自身仍在上涨就继续持有。

池子成员、回看长度、评分计算、持仓名额和比较频率决定这套思路如何实现；它们可以调整，但实验需要继续检验“上涨中的相对强势能否延续”这一收益假设。

### 定战场：按资产暴露与可交易性构池

观察范围是可通过ETF参与的跨资产趋势，权益部分以市场宽基和宽泛风格为主，并考察国债、黄金等不同资产暴露。成员应有清楚的底层资产与代表性，避免仅因最近上涨或回测贡献高而加入。

构池需要回答：

- 它代表什么市场、风格或资产风险？与现有成员有多少重叠？
- 它补充了哪种现有池子缺少的机会？新增相似ETF是否只是增加某种风格在排名中的候选数量？
- 在研究区间内何时真正上市可交易？历史、价格、成交与费用口径是否足以支持比较？

观察池可以扩充、替换或精简，数量由覆盖与可交易性决定。每项实验使用明确的成员名单，以便知道结果变化来自哪里。观察池的覆盖和同时持仓的分散程度要分别讨论。

池子可以持续维护，增删理由先落在资产覆盖、产品可交易性和重复暴露上。同一底层暴露优先选代表产品，不按回测收益挑选发行人或相似ETF；扩大候选数量也可能增加某种风格争取第一名的机会，不能仅凭池子更大就认定选择更中性。每轮保留成员版本，在同一段历史上反复按结果增删，仍会引入事后选择。

### 定信号：上涨才参与，落后就让出资金

1. 根据近期上涨速度与路径平稳程度，为每只资产计算趋势分数。上涨是参与资格，评分更高代表策略认为趋势更强。
2. 排除不符合上涨条件或附加过滤条件的资产，将剩余候选按分数排序。
3. 按排名选择目标持仓。有持仓后仍持续比较，不赋予先买入的资产优先权。
4. 持仓不再合格，或排名跌出目标持仓范围，就退出；有更强的合格候选则把资金转过去。
5. 没有合格候选时持有现金。

**相对排名触发的资金转移是这套策略的核心取舍。** 当前实验把目标持仓范围设为第一名，每个交易日比较一次；25日、加权回归公式、分数上限与跌幅阈值是这一实现的具体设置，详见下文。

### 定仓位与纪律：作为子策略，全仓第一名

**当前定位是组合中的一个趋势轮动子策略。其内部全仓持有合格候选第一名，没有合格候选时持有现金。** 它负责把分配给自己的资金集中到领涨资产，总组合通过子策略之间的资金分配承担分散与整体风险管理。

这里的“全仓”指分配给该子策略的资金，不代表总账户资产全部投入一只ETF。子策略内部不因主观判断临时减仓，不同时保留第二名，也不因原持仓仍在上涨而拒绝换入新的第一名。

这是主动选择集中暴露：持有第一名时，子策略资金承担该资产的涨跌；换仓信号出现前，快速反转也会直接影响子策略净值。因此当前按子策略研究和使用，不把它作为完整的家庭资产配置方案。总组合给它多少资金、与其他子策略怎样搭配，属于组合层的决策，尚未确定分配比例。

反转速度另记录“从观察峰值回落2倍信号前20日日对数收益标准差所需天数”，仅在10日内观察到阈值触发时统计；没触发不等于不会反转。路径只取此后第1至第10日收盘，未覆盖入场日余下行情与日内极值；信号前波动率只使用此前行情。行情使用原始价与后复权收盘价对齐决策价，这是不含费用的价格路径研究，不能当成已执行交易收益。第一名事件存在时间聚集及10日窗口重叠，正收益本身不能证明排名信号产生了额外预测能力。

### 第一名信号与同ETF、同年普通时点的对照

### 当前信号与退出规则

| 环节   | 当前规则                                      |
| ---- | ----------------------------------------- |
| 决策时点 | 每个交易日计划10:40执行                            |
| 价格样本 | 过去25个日线收盘价，加当前价格，共26个价格点                  |
| 动量评分 | 对数价格加权线性回归，权重从1递增至2；分数为回归斜率换算的年化涨幅乘以加权R²  |
| 合格候选 | 分数严格大于0、小于5，且通过跌幅过滤                       |
| 跌幅过滤 | 最近三段价格比值中，任一段低于0.95则排除；最近一段包含当前价相对前收盘价的变化 |
| 入场   | 空仓时买入合格候选第一名                              |
| 换仓   | 持仓不再是合格候选第一名时，卖出现持仓并买入新的第一名               |
| 清仓   | 没有合格候选时清仓                                 |
| 继续持有 | 现持仓仍为第一名时不主动调整数量                          |

分数中的“年化涨幅”只是25日趋势斜率的换算，用来排名，不是未来一年收益预测。R²描述这段价格路径与拟合趋势的贴合程度，不是盈利概率。

**排名退出是当前实验版本的一部分。** “趋势仍在就继续持有”是另一种退出规则，不能把它当成现有行为。分数上限5与跌幅过滤也都是实际影响进出的规则，它们的独立作用尚未分离。

日内−3%止损、成交量过滤和RSRS过滤均关闭。当前没有固定的单笔亏损止损线、移动止盈线或组合回撤触发线；跌幅过滤不等于账户亏损达到5%就退出。

### 当前仓位与执行边界

当前目标是单一持仓，建仓或换仓时投入可用现金，预留比例为0，实际仓位受费用、整手与成交情况影响。不按资产波动率缩放仓位，也不根据全池上涨成员占比调整总仓位；持仓不变时，不因价格下跌主动追加买入。

持有创业板、黄金与国债时，资金投入规则相近，承担的风险却不同；当前没有按风险缩放仓位。现有回测将整个回测账户视为该子策略的资金，用于观察它独立运行的表现，不能直接当作总组合表现。

当前脚本没有实现多策略资金隔离、组合预算或组合再平衡。接入总组合时，需要把下单资金限制在分配给它的预算内；降低该子策略占比或调拨资金由组合层决定。历史最大回撤不是未来损失上限。

当前版本属于研究策略，尚未完成实盘执行验证。代码按目标持仓记持仓天数，未按实际成交后快照核对；卖出失败或部分成交也可能造成实际仓位偏离单一持仓目标。这类执行问题应按事实修复，不能用目标持仓日志代替成交证据。

## 后续实验围绕什么展开

每次实验先回答它服务于下面哪个问题，并保持其他规则不变。结果同时看收益、回撤、交易成本及收益集中程度。

| 研究问题               | 对应实验的目的                           |
| ------------------ | --------------------------------- |
| 仓位是否与承担风险相匹配？      | 单独研究集中持仓、分散或风险缩放的取舍，不预先认定某种仓位更优   |
| 新资产是否补上了现有池子的机会缺口？ | 固定信号后对照池子变化，检查收益与风险改善是否跨年份成立      |
| 现有附加规则是否服务于收益假设？   | 分别核查分数上限和跌幅过滤的作用，避免多个过滤器同时叠加后无法解释 |

当前版本的平台风险指标、持仓重建、实际持仓段、固定10日路径及同ETF同年普通时点对照已补充。下一步将排名轮动与独立时序趋势、退出规则的作用用固定规则的完整账户对照区分，避免把某ETF的信号后行情直接当成可获得的账户收益。逐一剔除成员时，完整报告替代资产参与后的账户收益与回撤，避免只挑最好的子池。分钟执行口径和滑点成本单独核验，原始委托总笔数及逐笔盈亏口径尚未核对。后续对照保持相同日期、资金、费用和运行频率，改变频率后的结果单独比较。继续搜索更高收益的窗口、交易时点或ETF组合，不作为独立研究目标。

如果结果需要很窄的参数、少数年份或理想成交才能成立，应降低对收益假设的信心；如果一个改动提高收益却无法解释改变了哪种机会或风险，也不据此升级主版本。
