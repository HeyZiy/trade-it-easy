# 数据、规则与持有体验指标

研究的问题是：长期配置宽基ETF时，择时能否减少深亏和漫长等待，同时尽量保留收益？
先量出长拿的体验，再观察每种规则付出的收益代价和换来的改善。
不把“年化没有跑赢长拿”直接视为失败，也不因曲线平稳就认定择时有效。

## 使用

仓库根运行：

```text
python research/studies/broad_index_strategies/run_level1.py
```

只读取已有行情与PE缓存，按[标的配置](../assets.py)运行；不支持PE的标的省略估值策略。
结果在[一级对照](../results/level1/summary.md)。

统一比较长拿、月度移动网格、月末MA200、PE估值、唐奇安20/10、55/20和
MA20±1.5ATR20下轨退出。信号、成交、成本及网格路径均沿用原规则。
主表列全期指标；另对每月重新建账、持有满1/3/5年的窗口分别汇总。
各策略使用同起点同终点，起点前行情只用于指标；账户从现金启动，
不继承此前虚拟持仓。估值处于中间分位且没有明确目标时继续空仓。

## 统一设置

- 标的：assets.py中的12只ETF。没有可用PE源时省略估值策略，不替换为其他指数估值。
- 数据：东财后复权OHLC；信号与成交均在复权价格空间，100份取整属于复权份额模拟。
  未独立核验上游分红复权，也未改为原始价格加分红现金流账户。
- 资金与成本：初始100万元，单边0.06%，现金不计息，期末收盘估值不强制平仓；每年244个交易日。
- 窗口：各ETF从MA200首次可得之日起，至固定截止日2026-09-30。
  恒生科技缓存从2021-05-25开始，统一窗口为2022-03-18至2026-09-30。
  各标的窗口不同，跨标的全期结果不直接排名。

| 一级规则 | 定义 |
|---|---|
| 长拿 | 期初全仓买入持有 |
| 网格 | 几何步长3%，上下各10档，初始买10/20份；每月首个交易日用昨日收盘重定中枢，份额与现金不因重定直接变化 |
| 月末MA200 | 月末收盘高于MA200满仓，否则清仓；次日开盘执行 |
| PE估值 | 指数PE全历史分位<=30%满仓、>=70%清仓，中间维持；至少24期，交易日仅用严格早于当天的数据 |
| 唐奇安20/10、55/20 | 收盘突破此前20/55日最高价入场，跌破此前10/20日最低价退出；通道不含当天，次日开盘成交 |
| MA20±1.5ATR20 | SMA20和Wilder ATR20，上轨入场、下轨退出，区间维持；次日开盘成交 |

网格主路径为O-L-H-C，当日只能卖出昨日已有份额；跳空越过挂单按开盘价成交。
日线不能复原真实日内反复穿越次数，也未验证盘口成交容量。
均线与通道用完整历史计算指标后截窗，账户起点为空仓，首次明确买入信号后建仓。

## 指标定义

| 维度 | 指标 | 口径 |
|---|---|---|
| 收益 | 年化收益、较长拿年化差 | 原244交易日年化、含成本；不与XIRR混用 |
| 亏损深度 | 最大回撤、期末回撤 | 历史净值高点包括初始资金，首日买入成本和亏损计入 |
| 等待时间 | 最长水下交易日、当前水下交易日 | 连续低于此前高点的收盘观察数，恢复日不计入；回到前高即结束 |
| 日历等待 | 最长水下日历天、当前水下日历天 | 从前高日至恢复日；未恢复则至样本末日，包含周末和节假日 |
| 难受的频率 | 水下时间占比、深回撤时间占比 | 深回撤为较前高下跌至少20%的交易日占比；20%是描述阈值，不是择时或筛选条件 |
| 踏空 | 落后长拿时间占比、最长连续落后长拿交易日 | 同额初始资金下，策略净值严格低于长拿的观察数 |
| 踏空幅度 | 最大相对落后、期末相对长拿差 | 策略净值/长拿净值−1；与年化差的单位不同 |
| 操作 | 年均成交笔数 | 买单和卖单分别计数，不等于完整交易轮数 |

“水下”指未恢复此前净值高点，不是仍亏损于最初买入价。
相等前高按恢复处理，浮点比较容差为相对1e-10。
纯现金始终等于期初资金，不算水下；若同期长拿上涨，仍会计入相对落后。

未恢复的区间照常计入最长/当前水下时间，并标记“期末未修复”；
其最终修复时间尚未知，当前持续时间只是已观察到的下界，不据此估计必然回本日期。
日历跨度与水下交易日分别取各段最大值，两者可能来自不同区间。
首日成本造成的回撤以前高为期初资金计算，虚拟前高日期记为首个交易日。
缺失或非法净值会报错，不能通过删除缺失估值缩短水下时间。

## 怎样比较

以年化收益、最大回撤、最长水下交易日为核心，分别观察分布，不合成总分。
较长拿的回撤改善、水下缩短都以正值表示改善。

- 同时列出收益与回撤均改善、收益降低但回撤改善、收益增加但回撤恶化、两者均恶化的窗口比例。
  这些是严格比较，持平窗口不会被强塞进四类，因此比例不一定合计100%。
- “三项均不差比例”要求年化不低、回撤不深且最长水下时间不长；完全持平也计入。
- “回撤改善时年化差中位数”只在回撤确有改善的窗口中统计，负数表示收益代价；没有符合窗口时留空。
- 分别看1/3/5年，不把不同期限混在一起；同一窗口配对的差值先计算再汇总。
  不将不同指标的中位数拼成一条真实账户路径。
- 月度起点高度重叠，窗口数不等于独立样本量；各ETF全期窗口不同，不据此跨标的排名。

低仓位本身也可能降低回撤；本工具描述账户体验，尚未通过同仓位对照归因择时贡献。
