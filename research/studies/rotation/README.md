# ETF 跨资产趋势轮动

**在经济驱动有差别的资产之间，追随已经出现、但尚未结束的上涨；争取持续上涨带来的收益，接受晚买、晚卖和试错损耗。**

这是一项资产配置层面的趋势轮动子策略。我们先确定愿意参与哪些资产的行情，再用价格识别机会，把分配给该子策略的资金优先交给相对强势的资产。

## 我们相信什么，赚什么钱

我们愿意押注的机制是：盈利、利率、供需等条件发生变化后，变化可能持续，市场认识与资金配置也会逐步调整，因此价格不一定一次涨到位。盈利改善可能连续兑现，供给缺口需要时间修复，配置资金也可能分批进入。这些过程可能让一段已经可见的上涨继续发展。

策略希望赚的是**看见行情以后，行情还没走完的那一段**。底层资产的上涨提供获利机会；识别趋势和调配资金能否比被动持有更好，则需要另外验证。只看到策略赚钱，还不能说明轮动创造了增量。

这条信念有明确的失败条件：如果变化已经被一次性计入价格，或者我们识别到强势时行情已经接近结束，追入就可能只承担反转。如果后续上涨不足以覆盖失败交易、换仓费用与盈利回吐，这套方法也不成立。

## 如何参与：识别上涨，比较机会

相对排名进一步押注：**近期领先的资产，接下来仍值得优先持有，其优势足以补偿切换的成本和踏错节奏的损失。** 因此，原持仓还在上涨，并不自动构成继续持有的理由；换入资产能否提供更好的后续机会才是关键。相反，排名更高也不天然等于未来收益更高，这正是需要检验的部分。

## 愿意承担什么代价

- **晚买：** 等上涨已经表现出来再参与，主动放弃起涨前和最初一段收益。
- **晚卖：** 趋势或相对优势需要通过价格变化才能确认，退出前可能回吐利润，也可能把浮盈变成亏损。
- **试错与切换损耗：** 有些走强不会延续，有些换仓会换错；亏损交易、费用以及卖出后继续上涨都是可能付出的成本。
- **收益不均匀：** 有些时期机会少、反复失效，利润可能集中在少数成功行情。我们希望有效行情的收益足以覆盖这些损耗，不要求每次判断正确。

当前将它作为组合中的一个子策略研究。“全仓”只指分配给它的资金，不代表总资产全部投入一只ETF。子策略会集中承担当时持有资产的涨跌；总组合分配多少资金、如何与其他策略搭配，属于组合层决策，目前不在这里指定比例。

## 资产池的范围与维护依据

核心范围放在**资产配置层面的轮动**：市场宽基、少量主要风格，以及黄金、国债和少量代表性商品。选择这些范围，是为了覆盖有差别的经济暴露，并把候选限定在愿意持续参与的资产上。

| 范围            | 希望捕捉的变化            | 构池取舍                      |
| ------------- | ------------------ | ------------------------- |
| 国内股票市场与少量主要风格 | 国内盈利、估值与风格变化       | 宽基为底；成长、小盘、红利等代表需要各自有保留理由 |
| 海外主要股票市场      | 不同市场的盈利、政策与估值变化    | 按经济暴露选择代表，说明地域与指数之间的重叠    |
| 黄金            | 货币条件与黄金需求变化形成的价格趋势 | 作为独立资产暴露，不预设任何时候都能对冲股票    |
| 国债            | 利率变化形成的债券价格趋势      | 明确期限风险；中长期国债都不能直接视为现金     |
| 少量代表性商品       | 供需变化形成的价格趋势        | 说清具体商品及产品结构；单一豆粕不代表整个农业   |

每次增加、替换或删除成员，先回答三个问题：

1. **它补充了什么经济暴露？** 如果只是已有暴露的另一种产品表达，优先选择代表产品，避免重复候选改变竞争权重。
2. **为什么信号出现后仍可能有上涨空间？** 说明与持续变化的联系，不能只用某次消息刺激或历史涨幅作理由。
3. **是否愿意承担被选中后的价格风险？** 产品的期限、集中度、期货展期及交易溢价等特性，会影响实际参与的机会。
