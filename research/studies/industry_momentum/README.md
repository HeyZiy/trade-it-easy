# 行业动量轮动研究

生产规则见 [`strategy/industry_momentum.md`](../../../strategy/industry_momentum.md)；
生产引擎是 [`src/etf/industry_momentum.py`](../../../src/etf/industry_momentum.py)。
本目录只保留现行研究基线和仍能支撑当前规则判断的证据，历史版本不再保留脚本。

## 当前基线

| 文件 | 角色 |
|---|---|
| [`lM_v3_3_2.py`](lM_v3_3_2.py) | 研究基线：0.90 流动性优先去重，score≤0 连续 3 日出场，成本 −8% 限亏，浮盈 +12% 后保本线抬至成本 ×1.01 |
| [`lM_v3_3_4.py`](lM_v3_3_4.py) | 去重顺序对照：动量优先去重，其余规则同 v3_3_2 |

两份脚本的头部绩效都早于 R² 与成交台账修正：v3_3_2 的 75.58%、v3_3_4 的 9.78%
不能作为当前结论，必须按修正后的评分口径重跑后再对照。生产参数自 2026-10-07
起把相关性去重门槛降到 0.85 并重建标的池，研究基线仍保留 0.90。
