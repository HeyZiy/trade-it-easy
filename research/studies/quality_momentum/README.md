# 质量池 + 12-2 动量轮动交易纪律

当前维护 **v5（2026-10-11规则定稿）**，聚宽入口为 [pool_rotation_v5.py](pool_rotation_v5.py)，默认 `EXPERIMENT='clock'`。本目录保留影响当前选择的回测与对照；完整操作规则见[现行策略](../../../strategy/roe_quality_pool.md)，早期构池研究见 [roe_quality](../roe_quality/README.md)。

## 一、我相信什么，赚什么钱

**我相信盈利质量、成长、估值和低波条件能限定值得参与的股票范围，池内中长期相对强势能帮助选择新仓，因此先筛质量池，再用跳过最近一个月的动量分配新仓名额，希望获得质量股票的持有收益与强势延续收益。** 这是当前采用的收益假设，现有结果尚未把质量池、动量选择和持仓管理各自的贡献完全分开。

- **关键取舍：** 动量决定新仓优先级；买入后，只要仍符合质量池条件就留存。即使排名下降、出现更强候选，也不单凭相对落后换仓；质量条件确认不再满足时，即使持仓仍盈利也退出。
- **愿意付出的代价：** 接受强势反转、质量信息更新滞后、旧仓占用名额而错过新强者，以及少数股票和共同风格带来的回撤。质量池合格不保证股价上涨，低波门槛也不保证组合低回撤。
- **重新审视的理由：** 若同口径对照显示动量选仓持续逊于同池分散持有，或质量留存持续劣于排名替换，就需要重新审视相应选择。现有历史对照支持保留质量留存，尚不能证明这些规则在不同阶段都有效。

## 二、策略选择：交易范围与进退方式

### 观察什么

观察沪深主板股票，以盈利质量和成长限定经营表现，以估值限制买入价格，以波动条件控制个股近期价格风险。动量只在通过这些条件的股票中比较；不因最近涨得好就绕过质量门槛。

财务、估值与价格信号必须使用当时已知信息。质量条件、状态或行情缺失时保留未知，不能把缺数据当作质量恶化，也不能把未知候选当作合格新仓。

### 怎样买、持有和退出

- **参与条件：** 质量池确认通过，且新仓需要的动量历史、行业归属和交易信息完整。不另设动量必须为正的门槛，因此池内相对强者仍可能处于下跌中。
- **同时有多个机会时：** 先保留合格旧仓，再按动量从高到低补空位，并遵守新仓行业上限。候选被挡时接受空仓预算，不为填满仓位继续向后找。
- **买入后：** 继续检查质量资格；排名下降或动量历史缺失本身不触发退出。调仓时按统一预算调整留存仓。
- **退出或替换：** 质量池任一条件确认失败就退出，包括波动超限；不设置排名退出、固定亏损比例止损或浮盈回撤止盈。卖出受阻则保留退出意图，后续继续处理。
- **没有机会时：** 空缺名额对应的资金留作现金，不放大其余持仓预算，也不另配替代资产。

## 三、仓位与组合角色

**本策略使用独立资金池，负责承担质量筛选与动量选仓带来的股票收益和风险；本地以独立模拟账户记录。总组合分配比例尚未确定。**

- **可用资金：** 分配给该策略账户的资金；回测初始金额属于实验设置。
- **内部配置：** 当前最多6只，每轮执行开始时冻结单只目标市值为策略账户总权益的1/6。留存仓做差额再平衡，新仓使用相同预算；不足6只时剩余预算留现金。
- **集中风险：** 单只目标约16.7%，同一行业旧仓可因留存超过新仓上限；名额限制也不能消除共同风格暴露。等权是调仓目标，实际权重会随价格和成交情况偏离。
- **风险处理：** 使用质量退出和波动退出，不另设组合回撤减仓线或机械止损。历史回撤仍是需要承担的持有代价，不能把低波筛选理解为收益保护。

## 四、当前实现

### 入口与本轮股票池

将 [pool_rotation_v5.py](pool_rotation_v5.py) 整文件粘贴到聚宽策略回测编辑器，使用**分钟频率**。当前6只持仓、20日周期和各项阈值是本轮实现选择。

| 项目 | 当前设置 |
| --- | --- |
| 股票范围 | 沪深主板，代码以60或00开头，非ST；停牌只限制成交 |
| 盈利质量 | ROE_TTM > 12%；聚宽读取 `roe_ttm` 因子，`ROE_FACTOR_UNIT='ratio'`，换算为百分比 |
| 利润成长 | 最新已披露单季度合并净利润同比 > 10%，使用 `inc_net_profit_year_on_year` |
| 估值 | 0 < PE(TTM) < 30；0 < PB < 5 |
| 波动 | 61根有效复权收盘价形成60个日收益，样本标准差 × √250，年化波动率 < 35% |
| 动量 | 截至上一交易日的253根复权收盘价，剔除最近21根；剩余窗口末价/首价−1，跨231个交易日；同分按代码升序 |
| 新仓候选 | 仅当期动量前6名；受限制时跳过，不顺延至第7名 |
| 行业限制 | 新开仓后同一申万一级行业最多2只；旧仓不因行业超限强制退出 |
| 旧仓留存 | 质量条件确认通过就留存，无排名留存线；未知则暂缓判断 |
| 调仓与仓位 | 每20个交易日，最多6只，目标预算为总权益/6，保留留存仓差额再平衡 |

财务报告期与披露日均不得晚于上一交易日，估值、波动和动量同样使用该截止日；ST和成交状态使用当日已知信息。不启用解禁过滤、残差波动过滤或残差动量替换。

### 决策与执行

当前聚宽 `clock` 模式在调仓日 **08:00** 取昨收信息生成名单，**当日09:31** 检查交易状态、先卖后买。买入与等权调整只尝试一次，不追补买入；退出受阻仓每天09:31继续尝试卖出。预算按执行开始时的账户权益冻结，成交按实际持仓、可用现金和在途委托确认，数量按100股整手处理。

| 模式 | 相对差异 | 当前使用 |
| --- | --- | --- |
| `fixed` | 原14:55生成信号，次交易日09:31执行 | 仅作对照，尚无成绩 |
| `clock` | 08:00取昨收信息，当日09:31执行 | 现行默认 |
| `buy_retry` | 相对 `clock` 增加当日09:32—09:35补买，名单与预算冻结 | 未采用，尚无成绩 |

本地入口为 [quality_pool.py](../../../quality_pool.py)，每天**09:30启动一次**，直接运行 `python quality_pool.py`：先生成昨收信号或补判旧仓，再按计算完成后的实时行情模拟成交、处理退出，最后统一保存并推送一份报告。09:30是启动时间，成交不固定为09:30或09:31；`--dry-run` 预览完整流程，不写状态或台账。本地只做名义记账，不向真实账户下单；聚宽保留上表中的回测调度时点。

异常处理直接执行已确认的规则：新仓质量未知不买；旧仓质量未知保持数量并每日补判，已有确认退出不会因随后数据未知撤销。新候选行业缺失就跳过；旧仓行业缺失则暂停其等权调整并暂缓全部新开仓。整轮数据失败时次交易日重算，原20日节点不变。具体成交限制与恢复处理见[现行策略](../../../strategy/roe_quality_pool.md)。

## 五、影响当前选择的证据

下面按规则选择保留证据。平台完整回测、脚本内摘要和离线价格探针分别说明；旧规则下的单次结果只支持对应条件内的判断。

### 仍在质量池的旧仓，是否因排名下降退出？

- **改了什么：** [v4_1_2](pool_rotation_v4_1_2.py) 相对 [v4_1](pool_rotation_v4_1.py) 仅取消排名9的旧仓留存线，改为质量池内即留存。
- **关键结果：** 历史日频摘要中，累计收益183.22%→216.36%，最大回撤34.15%→24.92%；超额最大回撤约37.90%→38.35%，并未同步改善。取消留存线版年化11.75%，最大回撤区间为2021-09-09至2023-12-20。
- **当前决定：** 保留质量留存，排名只决定新仓优先级。
- **结论范围与复现：** 单次历史日频对照，不能外推为所有时期都应取消排名退出。价格路径中排名退出仓卖后20日中位上涨2.00%、胜过实际策略52.5%，仅是诊断线索；规则效果看完整账户对照。脚本记录设置为2016-01-04至2026-09-01、100万元；实际旧版导出存在10万元口径，涉及最低佣金时须核对，不能默认全部同资金。过程数据见 [exports](exports/)，路径诊断见[报告](reports/price_paths_v4_1_2026-10-10.md)。

### 波动超限是否只限制买入？是否增加10%止损？

- **改了什么：** [v4_1_3](pool_rotation_v4_1_3.py) 相对v4_1_2仅取消持仓的波动超限退出；另一个 [v4_1_1](pool_rotation_v4_1_1.py) 对照是在v4_1上增加每日10%开盘清仓止损。两项实验基线不同。
- **关键结果：** 取消波动退出后年化11.75%→12.31%，最大回撤24.92%→41.90%；10%止损对照的累计收益183.22%→83.73%，最大回撤34.15%→33.76%，止损实验两版实际资金均为10万元。
- **当前决定：** 保留波动超限退出，不增加10%机械止损。
- **结论范围与复现：** 波动退出对照仅有脚本内平台摘要；止损版有[完整诊断](reports/stop_loss_2026-10-10/report.md)与导出。卖后反弹和现金等待是观察到的路径，不能将其逐笔累加成止损造成的账户损失，也不能推导其他止损方式必然无效。

### 是否把调仓周期延长至40日？

- **改了什么：** 在v4_1基线上只把20交易日改为40日，实际初始资金10万元。
- **关键结果：** 同口径复算年化10.34%→16.40%，最大回撤34.15%→38.08%。2021—2022年贡献约84%的对数收益优势，剔除这两年后其余年份累计领先仅约9.5%。
- **当前决定：** 保留20日，不凭全期高收益采用40日。
- **结论范围与复现：** 单次历史日频对照，尚无现行v5下的同口径结论；10.34%为本地复算年化，不能与平台年化混用。见[总体对照](reports/rotate_period_v4_1_2026-10-10.md)、[年度结构](reports/rotate_period_v4_1_annual_detail_2026-10-10.md)及 [result_20.csv](exports/result_20.csv)、[result_40.csv](exports/result_40.csv)。

### 留存仓是否取消差额再平衡？

- **改了什么：** [v4_1_6](pool_rotation_v4_1_6.py) 相对v4_1_2仅保留旧仓数量不动，新仓仍按总权益/6买入。
- **关键结果：** 脚本内摘要显示，累计收益216.36%→193.19%，年化11.75%→10.94%，最大回撤24.92%→24.46%，超额最大回撤38.35%→39.21%。
- **当前决定：** 继续使用留存仓差额再平衡；现有摘要没有显示取消后在收益与回撤之间更有利。
- **结论范围与复现：** 仅有历史日频脚本摘要，没有v4_1_6过程CSV，未独立复算费用、换手和差异来源；不能据此认定再平衡贡献了确定数量的收益。

## 六、下一步只解决什么

下一次运行先保留实际区间、初始资金、分钟频率、模式与七类过程CSV，核对账户收益、回撤、实际成交、买入缺口和期末持仓。若比较盘前时钟的影响，就在相同资金、费用和分钟口径下只比较 `fixed` 与 `clock`；补买另作独立对照。当前继续保留 `clock`、关闭补买，不据缺失的对照结果宣称执行改动提升了收益。
