# 质量动量：经营支撑与价格兑现

当前维护 **v5（2026-10-11规则定稿）**，聚宽入口为 [pool_rotation_v5.py](pool_rotation_v5.py)，默认 `EXPERIMENT='clock'`。本文说明收益假设、交易选择与影响当前决定的证据；完整可执行规则见[现行策略](../../../strategy/roe_quality_pool.md)，早期构池研究见 [roe_quality](../roe_quality/README.md)。查已有实验先看第五节：按问题列出结论、报告与复算脚本，不必逐个翻目录。

## 一、我相信什么，赚什么钱

**核心主张：寻找有经营支撑、价格尚有回报空间，并开始得到市场认可的上涨机会。**

我相信，一部分公司的盈利能力和增长持续性不会被价格一次性充分反映。经营表现提供持有依据，买入估值影响剩余回报空间，价格走强则可能提示市场正在逐步认可这些经营表现。因此，希望先筛出值得参与的公司，再借助价格信号选择投入资金的机会，并给仍符合持有依据的仓位时间，赚取经营持续兑现、价格逐步反映其价值的收益。

这里的关键假设是：**市场已经开始反应，但尚未充分定价。** 经营好不等于股票回报高，过去涨得多也不等于未来兑现更快；目前尚未证明现有筛选和动量能识别这种机会。

### 各部分服务于什么判断

| 部分 | 希望解决的问题 | 不能直接作出的推论 |
| --- | --- | --- |
| 盈利质量与成长 | 上涨是否有经营支撑，这种经营表现是否可能延续 | 财务达标就一定有超额收益，因子越多胜率越高 |
| 估值约束 | 当前价格是否为未来经营兑现留下回报空间 | PE/PB低于固定上限就代表低估 |
| 价格信号 | 市场是否已在响应，资金现在参与是否比继续等待更有效 | 历史相对强势就代表正在启动，或必然同时改善收益、速度和盈亏比 |
| 持有与风险管理 | 持有依据是否仍成立，继续占用资金的收益与风险是否值得 | 条件仍合格就可以无限等待，或波动过滤能够保证小回撤 |

这些部分需要共同改善成本后的账户表现。价格确认可能减少等待，也可能使买价更高、剩余空间更小；持有更久可能容纳正常波动，也可能扩大亏损和资金占用。因此不把胜率、兑现速度或盈亏比分别当成某个模块已经具备的效果。

- **关键取舍：** 愿意让出一部分早期涨幅，换取市场开始认可的线索；买入后给持有依据兑现的时间，不单凭排名下降频繁换仓。v5目前以继续符合质量池条件作为留存依据，尚未建立对价格兑现进程的独立判断。
- **愿意付出的代价：** 接受确认偏晚、买入后反转、财务信息滞后、旧仓占用名额，以及集中持仓和共同风格带来的回撤。波动超限属于风险约束失效，不能一概解释为公司经营恶化。
- **重新审视的理由：** 若筛选在同口径对照中不能改善候选的收益与风险分布，就重新审视构池依据；若价格信号既不能改善资金使用效率，也不能改善成本后的收益与风险，就重新审视该信号；若留存规则使资金持续停留在缺乏回报的持仓中，就单独检验持有与退出方式。

### 当前实现距离这个主张还有什么差距

v5是这一方向的现有参考实现。ROE与单季度利润同比是经营表现的代理，尚不能证明增长持续性；固定PE/PB上限也没有测算剩余回报空间。12-2动量比较过去中长期相对强弱，跳过最近一个月且不要求分数为正，尚不能直接判断近期价格是否开始兑现。买入后仅按质量池资格留存，也未单独检查价格信号是否失效或等待是否过长。

因此，当前6只持仓、前6名截断、20日周期及各项阈值都需要接受这个主张的检验；已有回测盈利不能替代对收益来源和资金效率的验证。

## 二、策略选择：交易范围与进退方式

本节记录v5当前的交易范围与进退取舍；可执行规则见[现行策略](../../../strategy/roe_quality_pool.md)。上一节的收益主张用于指导后续研究，尚未转化为新的买卖条件。

### 观察什么

观察沪深主板股票，以盈利质量和成长限定经营表现，以估值限制买入价格，以波动条件控制个股近期价格风险。动量只在通过这些条件的股票中比较；不因最近涨得好就绕过质量门槛。

财务、估值与价格信号必须使用当时已知信息。质量条件、状态或行情缺失时保留未知，不能把缺数据当作质量恶化，也不能把未知候选当作合格新仓。

### 怎样买、持有和退出

- **参与条件：** 质量池确认通过，且新仓需要的动量历史、行业归属和交易信息完整。不另设动量必须为正的门槛，因此池内相对强者仍可能处于下跌中。
- **同时有多个机会时：** 先保留合格旧仓，再按动量从高到低补空位，并遵守新仓行业上限。候选被挡时接受空仓预算，不为填满仓位继续向后找。
- **买入后：** 继续检查质量资格；排名下降或动量历史缺失本身不触发退出。调仓时按统一预算调整留存仓。
- **退出或替换：** 质量池任一条件确认失败就退出，包括波动超限；不设置排名退出、固定亏损比例止损或浮盈回撤止盈。卖出受阻则保留退出意图，后续继续处理。
- **没有机会时：** 空缺名额对应的资金留作现金，不放大其余持仓预算，也不另配替代资产。

## 三、仓位与组合角色

**本策略使用独立资金池，负责承担质量筛选与动量选仓带来的股票收益和风险；本地以独立模拟账户记录。总组合分配比例尚未确定。**

- **可用资金：** 分配给该策略账户的资金；回测初始金额属于实验设置。
- **内部配置：** 当前最多6只，每轮执行开始时冻结单只目标市值为策略账户总权益的1/6。留存仓做差额再平衡，新仓使用相同预算；不足6只时剩余预算留现金。
- **集中风险：** 单只目标约16.7%，同一行业旧仓可因留存超过新仓上限；名额限制也不能消除共同风格暴露。等权是调仓目标，实际权重会随价格和成交情况偏离。
- **风险处理：** 使用质量退出和波动退出，不另设组合回撤减仓线或机械止损。历史回撤仍是需要承担的持有代价，不能把低波筛选理解为收益保护。

### 仍在质量池的旧仓，是否因排名下降退出？

- **改了什么：** [v4_1_2](pool_rotation_v4_1_2.py) 相对 [v4_1](pool_rotation_v4_1.py) 仅取消排名9的旧仓留存线，改为质量池内即留存。
- **关键结果：** 历史日频摘要中，累计收益183.22%→216.36%，最大回撤34.15%→24.92%；超额最大回撤约37.90%→38.35%，并未同步改善。取消留存线版年化11.75%，最大回撤区间为2021-09-09至2023-12-20。
- **当前决定：** 保留质量留存，排名只决定新仓优先级。
- **结论范围与复现：** 单次历史日频对照，不能外推为所有时期都应取消排名退出。价格路径中排名退出仓卖后20日中位上涨2.00%、胜过实际策略52.5%，仅是诊断线索；规则效果看完整账户对照。脚本记录设置为2016-01-04至2026-09-01、100万元；实际旧版导出存在10万元口径，涉及最低佣金时须核对，不能默认全部同资金。过程数据见 [exports](exports/)，路径诊断见[报告](reports/price_paths_v4_1_2026-10-10.md)。

### 波动超限是否只限制买入？是否增加10%止损？

- **改了什么：** v4_1_3 相对v4_1_2仅取消持仓的波动超限退出；另一个 v4_1_1 对照是在v4_1上增加每日10%开盘清仓止损。两项实验基线不同。
- **关键结果：** 取消波动退出后年化11.75%→12.31%，最大回撤24.92%→41.90%；10%止损对照的累计收益183.22%→83.73%，最大回撤34.15%→33.76%，止损实验两版实际资金均为10万元。
- **当前决定：** 保留波动超限退出，不增加10%机械止损。
- **结论范围与复现：** 波动退出对照仅有脚本内平台摘要；止损版有[完整诊断](reports/stop_loss_2026-10-10/report.md)与导出。卖后反弹和现金等待是观察到的路径，不能将其逐笔累加成止损造成的账户损失，也不能推导其他止损方式必然无效。

### 是否把调仓周期延长至40日？

- **改了什么：** 在v4_1基线上只把20交易日改为40日，实际初始资金10万元。
- **关键结果：** 同口径复算年化10.34%→16.40%，最大回撤34.15%→38.08%。2021—2022年贡献约84%的对数收益优势，剔除这两年后其余年份累计领先仅约9.5%。
- **当前决定：** 保留20日，不凭全期高收益采用40日。
- **结论范围与复现：** 单次历史日频对照，尚无现行v5下的同口径结论；10.34%为本地复算年化，不能与平台年化混用。见[总体对照](reports/rotate_period_v4_1_2026-10-10.md)、[年度结构](reports/rotate_period_v4_1_annual_detail_2026-10-10.md)及 [result_20.csv](exports/result_20.csv)、[result_40.csv](exports/result_40.csv)。

### 留存仓是否取消差额再平衡？

- **改了什么：** v4_1_6 相对v4_1_2仅保留旧仓数量不动，新仓仍按总权益/6买入。
- **关键结果：** 脚本内摘要显示，累计收益216.36%→193.19%，年化11.75%→10.94%，最大回撤24.92%→24.46%，超额最大回撤38.35%→39.21%。
- **当前决定：** 继续使用留存仓差额再平衡；现有摘要没有显示取消后在收益与回撤之间更有利。
- **结论范围与复现：** 仅有历史日频脚本摘要，没有v4_1_6过程CSV，未独立复算费用、换手和差异来源；不能据此认定再平衡贡献了确定数量的收益。

## 七、近期换手率分组探针

**问题：在v5质量候选中，近期换手低、中、高的股票，后续收益分布是否不同？相同方向的差异在强动量候选中、控制动量等变量后是否仍存在？** 本轮仅观察信号，不下单、不改池门槛和退出。修正版已完成130期正常采样：不支持直接加入低换手收益因子；风险差异与控制后中间组的线索分别见下文。

入口为 [study_v5_turnover_probe_jq.py](study_v5_turnover_probe_jq.py)，复制整个文件到聚宽策略回测，选择**每天频率、2016-01-04至2026-09-01、100万元**。不读取任何本地缓存或其他脚本；原v5入口保持不动。复用v5的历史构池、财报可见性、ROE_TTM、波动与动量计算，并复用单因子工具的保留同分分组和HAC汇总函数。本地测试核对拷贝源的一致性。每20交易日盘前冻结候选、因子和组别，不因数据失败改变采样时钟。

| 项目 | 固定设计 |
| --- | --- |
| 因子 | T−1以前20个市场交易日的 `valuation.turnover_ratio`（平台百分比口径）算术平均，20日必须完整有效；不拿更早日期凑数，不将停牌缺记录补0 |
| 全池 `pool_raw` | 当期v5质量候选内按平均换手率分低、中、高三组，各约三分之一 |
| 强动量层 `strong_raw` | 先按12-2动量保留最高三分之一，再在这部分候选中按换手率分三组；未直接把前6名拆成极小的组 |
| 控制后 `pool_neutral` | 当期截面回归 `log(1+换手率均值)` 对行业、log总市值、12-2动量、vol60，按残差分三组；检验是否只重复已有暴露 |
| 分组约束 | 同分不按代码拆开；无法形成三组、任一组少于5只或控制变量缺失时，相应组别缺测；原候选仍在明细保留 |
| 后续表现 | T日开盘至T+20/40/60交易日开盘的统一后复权报价收益；同时报上涨比例、端点跌幅至少15%的比例。后者不是区间最大回撤 |
| 比较与分段 | 保留低、中、高全部结果；主对照为同一采样期低组减高组。汇总全期、2020年起和逐年；不把重叠前瞻窗口连成可交易账户净值 |
| 缺测 | 分组先冻结；停牌、缺报价、异常、末尾期限不足分别保留状态。完整组内任一成员缺收益，整组收益缺测；另列已知样本均值及覆盖率，不能混为完整组结果 |
| 统计 | 每期等权，HAC滞后为期限/20；未到期尾部只报截断数量，中间有缺测时不压缩间隔计算HAC，不凭单个显著期限决定加入因子 |

平台空账户的收益曲线与夏普无解释意义。历史换手率优先使用 `get_valuation`，平台未提供时使用 `get_fundamentals_continuously` 查询同一估值表；查询窗口始终截至T−1。前瞻行情在期限已经到达后查询，三个期限从同一份后复权报价中计算。仍未模拟涨跌停成交、费用和资金约束，也没有把质量池内候选等同于实际新仓。

输出共四份，统一前缀 `quality_momentum_v5_turnover_probe_`：

- `periods.csv`：每轮各组的完整组收益、已知样本均值、上涨/大亏比例与覆盖率。
- `samples.csv`：全部原候选、20个逐日换手值及均值、财务披露日、动量和控制变量、冻结组别、各期限端点报价及缺失原因。

运行结束下载这四份即可分析，无需截图平台空账户曲线。若只看到全池差异而强动量层和控制后不支持，就不据此增加新仓条件；若差异值得继续研究，再单独设计完整账户对照。
