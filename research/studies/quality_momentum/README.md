# 质量池相对强弱轮动

唯一规则说明见 [strategy/quality_pool.md](../../../strategy/quality_pool.md)，聚宽当前实现为 [pool_rotation_v5.py](pool_rotation_v5.py)。本页解释为什么保留这套设计、证据到哪里，以及投入实际资金前还要确认什么。

## 一、策略逻辑与取舍

用盈利、成长、估值和波动约束限定可参与的股票，再以中长期相对强弱决定新仓优先级；买入后，只要仍符合池资格，就给持仓继续兑现的时间。收益假设是：这些约束下的部分强势股可能延续表现，持有能够承接这段收益。

已有结果更支持较长时间的选股与持有，不支持更快兑现或跨阶段稳定超额。

| 环节       | 当前选择与理由                                            |
|------------|-----------------------------------------------------------|
| 准入       | 盈利、单季成长、估值和波动共同限定资格                    |
| 新仓       | 在池内按12-2动量排序，只从前6名补位                       |
| 留存与退出 | 旧仓资格通过则留存，不按排名下降退出                      |
| 周期       | 每20交易日检查、补位和等权调整；已确认退出受阻则继续处理  |
| 组合       | 最多6仓、每仓预算为权益的1/6，新仓同业上限2只，空位留现金 |

## 二、已经回答的问题

以下是已有证据支持的取舍，不是新的实验清单。旧版本与各实验单文件结果分别保留原口径，不能相互拼接成收益归因；v5摘要按日频归档（此前误记为分钟），分钟频率暂不回测。

| 问题                       | 已有结果                                                                                                | 当前决定                                                 |
|----------------------------|---------------------------------------------------------------------------------------------------------|----------------------------------------------------------|
| 动量是否有选仓信息         | 同池日频11账户中，动量年化11.00%、最大回撤26.16%；随机中位3.80%、34.43%。2020年起只胜5/10，优势集中早期 | 保留动量；不宣称稳定alpha或快速兑现                      |
| 排名下降是否退出           | 旧版取消排名留存线后，累计183.22%→216.36%，最大回撤34.15%→24.92%                                        | 资格合格旧仓留存，排名只用于新仓                         |
| 是否加10%固定止损          | 旧版对照累计183.22%→83.73%，最大回撤34.15%→33.76%                                                       | 不加该固定止损                                           |
| 波动超限是否仍退出         | 旧版取消后年化11.75%→12.31%，最大回撤24.92%→41.90%                                                      | 保留波动资格退出                                         |
| 留存仓是否停止等权调整     | 旧版取消后年化11.75%→10.94%，最大回撤24.92%→24.46%                                                      | 保留差额再平衡                                           |
| 是否延长为40日             | 旧版年化10.34%→16.40%，最大回撤34.15%→38.08%，优势集中少数年份                                          | 保留20日，不按最高全期收益挑周期                         |
| 是否改为每日检查或每日调仓 | 退出日检产生更多空位；完整日调仓更满仓仍落后，交易和替换增多                                            | 保留20日整体节奏；不把差异断言为已独立证明的财务降噪机制 |
| 是否增加更多筛选或排序     | 近期确认、正动量、低换手、财报后持续强势均缺少采用依据；现金支撑与TTM/扣非替换也未显示稳定改善          | 不叠加这些条件，停止逐个尝试新因子                       |


## 五、目录与使用

```text
quality_momentum/
├─ README.md                 当前决定、规则取舍及使用边界
├─ pool_rotation_v5.py       唯一当前聚宽实现
├─ experiments/              既有实验单文件，按需复现
├─ internal/                 实验源码、生成及分析函数
├─ exports/                  平台原始输出
```

运行当前聚宽实现使用日频率、默认`clock`，分钟频率暂不安排回测；本地入口为根目录 [quality_pool.py](../../../quality_pool.py)，实际调度和异常处理以[规则说明](../../../strategy/quality_pool.md)为准。

复现既有实验：`python -m research.studies.quality_momentum.internal.build_platform`生成排序对照与换手/财报探针；现金支撑和增长口径分别使用`internal.build_cash_support`、`internal.build_growth_basis`。均输出到`experiments/`，支持`--check`。历史实验不是待执行队列。
