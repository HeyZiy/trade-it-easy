# 质量池 + 12-2 动量轮动

先用财务、估值和低波条件筛出质量池，再按跳过最近一个月的中长期动量选择新仓；旧仓按质量池留存。
本目录维护 **6只集中持仓版v5（2026-10-11规则定稿）**，从 `roe_quality` 的历史研究中分离。

当前入口是 **[pool_rotation_v5.py](pool_rotation_v5.py)**，整文件粘贴到聚宽策略回测编辑器，
统一使用**分钟频率**。默认`EXPERIMENT='clock'`：盘前08:00取昨收因子，当日09:31执行；
`fixed`沿用原14:55信号/次早执行，`buy_retry`仅相对clock增加当日09:32~09:35补买。
数据未知/质量失败/交易障碍分开、故障恢复、删除旧排名依赖和行业缺失处理直接合并，
不用分别跑收益实验；时钟和买入重试保留为独立对照。定稿采用`clock`，补买关闭。
用户提供的聚宽摘要：**收益207.03%、年化11.43%、最大回撤24.71%、超额最大回撤38.63%**，
最大回撤区间2024-06-04~2024-11-22。按当前默认`clock`归档；实际运行设置和本次过程CSV未留存，未独立复算。
`fixed`与`buy_retry`尚无成绩，不宣称盘前时钟或补买的独立收益效果。
完整交易规则见[现行策略](../../../strategy/roe_quality_pool.md)。回测摘要与实验记录保留在本目录；本地模拟同步现行6只规则，使用独立台账与状态。

## 变体实验结论（2026-10-10，均单次回测，无随机种子）

| 变体 | 改动 | 结论 |
| --- | --- | --- |
| `v4_1_1` | 每日10%开盘清仓止损 | 否决：收益83.73%、回撤33.76%（10万元口径），卖在恢复低位 |
| 40日调仓 | ROTATE_EVERY 20→40 | 未采纳：年化16.40% vs 10.34%（同口径复算），但优势84%来自2021-22两年，回撤38.08%更深 |
| `v4_1_3` | vol60仅限制买入 | 否决：回撤24.92%→41.90%，vol退出的保护作用确认有效 |
| `v4_1_4` | 选池追加残差波动率<27.5 | 否决：总回撤没动，超额最大回撤38.35%→44.64% |
| `v4_1_6` | 取消留存仓差额再平衡（调仓日不动留存仓，仅新仓按预算买入） | 成绩待回填：差额再平衡的首次消融，对照定版 v4_1_2 |

离线诊断（脚本在 `internal/`，报告在 `reports/`）：价格路径（大亏=入场端
个股性跑输，非退出太慢）、排名有效期（动量优势20日内弱、40-60日才显著）、
风险计量（爆雷率跟随残差而非总波动，平台验证否决）、回撤分解（回撤住在
集中度×动量逆风层，不是市场β）、行业上限探针（被挡候选前瞻收益更差，
上限有保护）、波动率缩放反事实（回撤非波动率事件，缩放砍牛市不护逆风，
否决）、残差动量探针（残差分与原动量Spearman仅0.235，换入票前瞻更差，
r20链年化13.3%→3.1%，否决——池内动量超额依赖顺风格成分，剥掉即失效）。
