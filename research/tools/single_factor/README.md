`original_note.md` 是用户指定笔记的原文副本，`original_code.py.txt` 是其中完整示例代码。
原文中的“可直接运行”、统计阈值和结果示例不作为本研究结论。
`single_factor_test.py` 是修订后的独立研究脚本，不依赖 ROE 策略文件。

## 当前推荐：回测编辑器单文件版

你的使用方式是聚宽回测编辑器，直接复制 `roe_factor_study_jq.py` 的全部内容即可。
不需要上传其他模块、不需要本地JQData账户；平台数据权限仍以当前账户为准。
后面的多文件入口保留给研究环境，当前不用它们。

回测页面设置区间2016-01-04～2026-09-01；资金对该诊断没有影响，因为脚本不下单。
每20交易日选股，财务/估值和收盘截止T−1，T日14:55固定因子与分组。
T+1日9:31读取已知开盘报价，下一轮T+1日9:31才计算已经发生的区间收益。
首个有效指标要等第一个完整20交易日区间结束；期末未完成区间不纳入。

默认同时分析1日/5日 × 原始/行业-log市值中性化四组，查询共享原候选池的61根收盘。
`PLOT_MODE='spread'` 展示最近完成区间的最高组减最低组收益差，单位百分点；
可改为 `'ic'`、`'groups'`、`'coverage'`、`'off'`。
`'groups'` 会显示20条组收益线，建议只在需要细查时启用。
画线是区间指标，非累计净值；非评价日沿用最近有效值。
缺测不会填0，平台可能继续显示该线旧值，因此覆盖率与最终日志是判断缺测的依据。

最终日志输出每组IC/ICIR、普通与HAC均值t、五组平均收益/有效期数、
高减低差、年度分布、覆盖率、名单换手和筛选请求异常。
页面的策略收益/夏普来自未交易账户，不代表这些分组，请看自定义指标和汇总日志。
不需要导出交易明细，跑完可直接复制日志分析。

脚本使用动态前复权，在退出日重新查询已过去的入场开盘，使其与退出日真实报价对齐，
避免送转除权被误算成大跌。停牌或缺失端点仍标记缺测，不模拟延迟卖出。
开盘报价不等于9:31实际撮合，也未模拟涨跌停买卖限制、成交量、滑点或税费。
本地用模拟数据验证了候选池一致性、逐期时间边界、除权及停牌行为，未运行真实平台回测。

## 参数和扩展

- `factor='gap'`：截至 asof 当天开盘价 / 前一交易日收盘价 − 1。
- `factor='momentum', lookback=1` 或 `5`：截至 asof 的累计涨幅，需要窗口+1根完整日线。
- `factor='alpha191_001'`：调用聚宽研究环境 `jqlib.alpha191.alpha_001`。
  这是官方 Alpha191 公式，不再以跳空收益冒充；本地没有 jqlib 时明确报错。
- `frequency='monthly'`：完整月的最后一个交易日生成信号。
- `frequency='trading_days', rotate_every=20`：从 start 后第一个交易日起每20交易日生成信号。
- `groups=5`：G1因子最低、G5因子最高，不按结果事后反转标签。
- `neutralize=True`：原始与申万一级行业、log总市值回归残差分别测试。
- `mad_scale=None`：默认保留原始排序；设置为3可启用MAD截断，零MAD时跳过截断。
- `min_ic_stocks=20`：少于20个完整因子/收益对时该轮IC缺测，不是收益有效性的门槛。
- `hac_lags=3`：IC均值的Newey-West滞后参数；应预先设定，不按显著性挑参数。

自定义股票池回调：

```python
def my_pool(api, asof, signal):
    # 使用截至asof/信号时已知的信息，返回股票代码列表。
    # 不用未来收益、不按未来是否退市删股票。
    return api.get_index_stocks('000905.XSHG', date=asof)

cfg = Config(factor='momentum', lookback=5, frequency='trading_days')
tables, snapshots = run_study(cfg, pool_provider=my_pool)
```

注意：传入自定义回调时不会再执行默认指数池的ST/停牌/上市年龄筛选。
要研究 ROE 策略，回调应复现该策略在每个信号时点的完整候选池；换成沪深300不能解释其结果。
ROE策略的财务/行情截止T−1、信号日状态、解禁筛选和轮动日期应逐项对齐。
已通过 `roe_pool.py` 接入原候选池函数，本地模拟数据上核对了名单与原策略一致。
尚未在聚宽历史数据上执行，不声称已完成ROE因子有效性验证。

## 相对原文的修正

1. 修复语法；用 `get_all_securities(..., date=asof)` 获取历史上市信息，
   `get_price(..., fields=['paused'])` 获取停牌状态，`get_industry(..., date=asof)` 获取历史行业。
   不使用不存在的 `get_extras('list_date'/'suspended'/'sw1')`。
2. 市值查询显式包含股票代码，用代码对齐；使用log总市值，缺失控制变量不填0。
3. 因子和控制变量截至信号日T−1；理论入场T+1开盘，退出下一轮信号T+1开盘。
   不是聚宽策略9:31撮合价格。保留窗口完整且退出不超过end的区间，不把月中结束当月末。
4. 所有行情明确 `fq='post'`，统一复权口径；因子涨幅不填补停牌日，不跨缺失日凑窗口。
5. 在查看未来收益前固定分组；同分不按股票代码人为拆分，无法形成全部组时缺测。
6. 因子、收益和控制变量不以0补缺。某组任何成员退出报价缺失，该组整轮收益缺测；
   IC使用完整配对样本，同时报告覆盖率，它仍可能受非随机缺失影响。
7. ICIR保留正负号。普通t、Newey-West均值t、年度IC分别报告；
   IC存在缺测期时不压缩时间间隔计算HAC，不套“0.02/0.2即合格”的硬标准。
8. 分组收益和基准使用相同入场、退出日期，收益曲线标在退出日。
   累计曲线一旦缺测便停止，避免补0制造连续净值。
9. 输出每组有效期数、覆盖率、最高减最低组收益差和等权目标名单换手；
   换手不含持有期权重漂移，不能当作实际成交换手。

## 如何解读与限制

本脚本测的是特征与后续报价收益的关系，不是可成交、扣费后的策略收益。
未模拟涨跌停、成交量约束、停牌延迟退出、滑点、税费和公司退市结算。
入场/退出停牌或无报价会缺测，不删除这些股票后悄悄重算组合。
不为了把曲线接起来而将缺失收益设为0或−100%；需要逐笔原因审计和适当的损失/结算口径。
行业数据历史覆盖、财务数据修订等仍受数据供应商限制。

完整候选池的IC可能不强而头部有效；也可能IC较好但扣费无法交易。
看平均分组差异、按年稳定性、样本覆盖，再回到策略撮合回测，不能仅看最终曲线严格单调。
已经看过2016–2026历史结果，因此年度切片只是诊断，不是假装未见过的样本外验证。
在真正后续验证中预先固定因子方向、窗口和调仓规则，不以试到t>2为停止条件。

ROE降序−22.0%、回撤60.3%；5日排序+89.6%、回撤42.4%。

### 信号层诊断实跑结果（2026-10-04，roe_factor_study_jq.py 平台回填）

区间 2016-01-04~2026-09-01，130 轮，候选均 121.2（最小 2/最大 258），
筛选异常放行 0 次，配对覆盖 99.7%；t_HAC 全部 NA（未出，判读以 t_iid 为准）。

| 组 | IC | ICIR | t_iid | 高减低/期 | 单调性 |
|---|---|---|---|---|---|
| M1_raw | +0.0054 | +0.032 | +0.35 | +0.34pp | 否（G3谷底） |
| M1_neutral | +0.0077 | +0.062 | +0.68 | +0.07pp | 否 |
| M5_raw | +0.0120 | +0.073 | +0.81 | +0.16pp | 否 |
| M5_neutral | +0.0087 | +0.081 | +0.90 | +0.01pp | 否 |

年度符号漂移大：2024 年 M1/M5 IC +0.165/+0.174，2026 迄今 −0.17/−0.075。
**判读：1d/5d 动量在 v1_3 候选池的 20 日窗口上无全池区分力（|t| 全部 <2）。**
策略层 random(+29.4%) ≪ 动量(+85.6%) 的差距在信号层没有对应截面梯度，
剩余候选解释：(a) 头部专属效应（取前10≈top 8%，全池IC看不见）；
(b) 高波动倾斜（涨幅头部≈涨停/高波集中，赚波动放大贝塔）；(c) 小样本运气。
"IC 可能不强而头部有效"由旧警示升级为主要待验假设，验证需另行预注册。

同日补跑 **pool_ic_probe_v1.py（Q2+头部检查）**：128 轮，in 组均 121 只、
涨停区均 0.2/最大 5（v1_1 头部不退化，抽签伪影为无池专属）；
Q1 复测 IC +0.0029 / t=+0.16（与上表交叉印证）；
**Q2 准入价值 fwd_in +0.89% vs fwd_out +0.68%，差 +0.20%，t=+0.61 → 池为装饰**。
按预注册：ROE/单因子族信号层账目结清（无区分+装饰），"池+趋势门"支线
前置未过、判死归档；动量≫random 的 56pp 剩余解释收窄为 (a) 头部凸性、
(b) 高波动集中+复利路径。验 (a) 需在探针 resolve 里加"每轮前10均值−池均值"
差值序列出 t，另行预注册，不追则封存。

建议顺序：

1. **先补诊断**：在原策略实际选股日的完整候选池中同时测1日、5日涨幅，
   分别看原始与行业/log市值中性化的IC、五组差异和年份分布。
   若每轮选股快照不可得，需移植原候选池函数到研究环境并校验与策略一致，而非换指数池。
2. **再决定排序**：中性化后仍有效，才支持个股价格强弱；
   中性化后显著弱化，需进一步分别控制行业和市值，不能一概断言是行业动量。
   仅靠年度汇总无法识别真正的收益来源。
3. **独立审计质量筛选**：单季度ROE×4适合原实验对照但不是TTM，
   后续比较持续盈利/多期ROE等口径；改财务口径时不要同时改排序、持仓数和门控。
   ROE降序失败不等于ROE硬筛选无效；筛选贡献需要保留/移除该条件的独立对照。
4. **基础实现问题另开修正版**：核对PE/PB是否须为正、缺失财务/状态筛选的放行逻辑、
   停牌到期退出和现金分配失败原因。修正后先恢复1日排序跑基线，避免混入因子实验。

此轮没有改动ROE交易脚本，也没有预先实施行业中性化交易、财务阈值或趋势门控。
