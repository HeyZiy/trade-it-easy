# 质量池 + 中期相对强弱轮动

状态：现行规则 2026-10-05 定稿。仅用于独立策略账户/独立回测，处理该账户全部持仓，
不能直接套用在含其他策略持仓的真实账户。
代码：[pool\_rotation\_v3a.py](../research/studies/roe_quality/pool_rotation_v3a.py)，整文件可直接粘贴聚宽。
研究过程与证据：[README\_pool](../research/studies/roe_quality/README_pool.md)。

## 策略在做什么

先用财务、估值和低波条件确定可考虑的股票，再在池内优先持有中期表现较强者。
最多20只，保留仍合格且排名未明显退后的旧仓，空位补入强者，每20个交易日检查一次。

质量池是超额的主要来源，排序负责在池内挑选与留存。强弱分数刻意跳过最近
20个交易日的涨幅，只衡量截止21天前的100日趋势：近期刚好飙涨的股票不因这一段
被追进组合，排名奖励的是走得稳的股票。这里的"相对"指池内股票之间的强弱，
不要求收益为正。窗口与20/30名留存是登记规则，未证明最优。

## 一、股票池

| 项目   | 规则                                        |
| ---- | ----------------------------------------- |
| 范围   | 信号日历史A股主板；代码以60或00开头                |
| 财务截止 | T−1交易日；报告期有效且披露日不晚于截止日              |
| 质量   | 最新单季度ROE × 4 > 12%                  |
| 成长   | 平台最新季度净利润同比 > 10%                   |
| 估值   | PE(TTM) < 30，PB < 5；仅设上界      |
| 波动   | 最近61根完整收盘形成60个收益；样本标准差 × √250 < 35% |
| 状态   | 排除信号日ST、停牌股票                        |
| 解禁   | 排除信号日起未来90自然日内存在任意已知解禁事件的股票         |

ROE×4 是单季度的年化近似，有季节性影响。PE/PB 没有正值下界，负值也可能通过；
这点保留是为了对齐既有筛选，不能据此解释为所有入池股票都具有低估值和持续盈利。
监管函、减持计划等尚无完整数据源的条件不包含在本版。

## 二、怎么选

强弱分数：`R = P(T−21) / P(T−121) − 1`。分子取21个交易日前收盘，分母取
121个交易日前收盘，两端相隔100个交易日；使用聚宽真实价格模式下的历史复权收盘。
最近20个交易日的涨跌不进入分数；股票上市不足121个交易日时无法计分。
按 R 降序排名，同分按股票代码升序，结果可重复。

1. 旧仓仍在质量池、且池内排名 ≤30，保留。
2. 出池或者排名 >30 的旧仓，计划退出。
3. 从当期前20名中按排名依次补空位，最多持有20只。
4. 不为排名21～30的新股票开仓；这一区间只保护已有持仓。
5. 新候选缺少计分所需收盘时不能参与排名；已有池内持仓若缺失排序行情，整轮暂停。

排名只在调仓日重新判断，期间每日波动不触发换仓。20交易日是检查间隔，股票可以
持有多轮。池内所有股票过去100日都下跌时，仍按相对强弱选择，没有正动量或市场
均线门控。

例：已有20只，A跌至第25名仍保留，B跌至第31名退出；第8名的未持有股票补入B释放的
名额。若20只旧仓都在前30名内，就不因出现新的前20名股票而强制替换。

## 三、怎么买、配多少钱

T日14:55生成名单；质量、估值、波动和强弱都截至T−1收盘，状态过滤使用T日当时信息。
下一交易日09:31按冻结名单先卖后买，实际价格由平台撮合决定。
沿用ROE研究的信号时钟，T收盘涨跌不参与这一轮，实际买入相对T−1信息有额外延迟。

每轮执行开始时冻结：`单只目标市值 = 策略账户总权益 / 20`，即每只5%。

- 留存股票做差额再平衡：高于预算减持，低于预算补足；交易差额不足100股则不动。
- 新股票直接按预算买入，不等待均线金叉或回踩确认。
- 只选到5只时，目标股票仓位约25%，其余留现金；不把5只放大到每只20%。
- 买入数量为100股整数倍，并按滑点、比例佣金和最低佣金检查可用资金。
- 不使用未成交卖单的预计收入；资金不足时少买或留现金，不提高其他股票的预算。

5%是调仓时的目标预算，整手、价格变动和成交限制会形成偏离。期间允许权重随价格漂移。
先执行待退出仓，再减少超额留存仓，最后按目标名单顺序补不足，旧仓在名单中排在新仓前。
该顺序是执行约定；现金受限时，它会影响实际组合，须在成交回测中保留。

## 四、怎么卖、卖不掉怎么办

策略退出只有两个信号：出池，或池内排名跌出前30。留存仓的等权减持不属于完整退出。
没有固定20天到期清仓，没有价格止盈止损，也没有依据市场均线自动清仓的规则。

| 情况                       | 处理                        |
| ------------------------ | ------------------------- |
| 出池/排名退出，正常可卖             | 下一交易日09:31退出              |
| 停牌、跌停、可卖量不足或部分成交         | 剩余持仓加入退出队列，每交易日09:31重试    |
| 退出尚未完成                   | 继续占用持仓名额；实际持仓和在途买单合计最多20只 |
| 新一轮重新入选的待退出股票            | 按新的有效名单撤销其退出计划            |
| 买入时停牌、ST、涨停、价格无效、资金或整手不足 | 跳过该股票，留现金；不临时改买第21名       |
| 买入或等权调整未完成               | 本轮不逐日追补，下一调仓轮重新判断         |
| 多日后才退出成功                 | 腾出的现金等待下一调仓轮，不用旧名单补买      |

## 五、运行与记录

日志默认精简：`VERBOSE_LOGS=False`，不逐笔打印调仓信号、委托和买卖受阻；严重的数据/
下单异常保留提醒，同一异常只提醒一次，完整事件记录在events表。持仓读取先检查
`positions.keys()`，避免聚宽兼容容器对缺失键逐只告警。需要逐笔排查时把
`VERBOSE_LOGS` 改为 `True`。

回测或模拟结束时导出七张CSV：nav、signals、members、events、orders、decisions、
holding_periods，文件名前缀 `pool_rotation_v3a_`，通过 `write_file` 写入聚宽
"投资研究"根目录，从文件列表下载；结束日志检索"诊断汇总"和"文件位置"。
决策与持有期表先下载，分析受阻或异常时再下载events表。

退出原因标记分两类：`out_of_pool`（出池，附依次筛选的首个未通过环节，如
roe_low、profit_growth_low、pe_high、pb_high、vol_high、st、paused、unlock_90d）
与 `rank_below_buffer`（跌出30名）。诊断口径与全部实验记录见研究目录README。

本地模拟执行以已记入模拟账户的成交为事实：先记账卖出，再按实际现金与持仓名额
缩减或跳过原买单，预算和目标名单不重算。退出记账失败的实际剩余持仓保留在退出
队列；买入或等权调整失败仍等下一调仓轮。开始记账前消费当轮名单并保留完整退出
意图，执行后核对剩余持仓；中途终止后只恢复退出重试，不重放旧名单的买入或等权调整。
