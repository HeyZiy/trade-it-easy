# 质量动量

以盈利质量、成长、估值和波动条件筛出质量池，再按池内中长期相对强弱选择新仓。
最多持有6只，每20个交易日调仓。持仓仍符合质量池条件就继续持有，空出的名额从当期强弱前6名补入。

## 一、质量池条件

范围为沪深主板、代码以60或00开头的A股。股票须同时满足以下条件：

| 条件     | 标准                                 |
|----------|--------------------------------------|
| 盈利质量 | ROE_TTM > 12%                        |
| 利润成长 | 最新已披露单季度合并净利润同比 > 10% |
| 市盈率   | 0 < PE(TTM) < 30                     |
| 市净率   | 0 < PB < 5                           |
| 波动     | 60个交易日年化波动率 < 35%           |
| 股票状态 | 非ST                                 |

ROE_TTM按最近四个连续已披露单季度的归母净利润之和除以最新可见期末归母权益计算。波动率使用61根复权收盘价形成的60个日收益，取样本标准差并乘以√250。

利润成长使用含少数股东损益的合并净利润，同比为本期与上年同季度的差额除以上年同期绝对值；上年同期为0或数据缺失时视为未知。

财务、估值、波动和强弱均截至上一交易日收盘；财报报告期与披露日均不得晚于该截止日。ST与停牌状态使用当日已知信息。停牌只限制成交。

## 二、排序与补位

取截至上一交易日的253根复权收盘价，剔除最近21根，用剩余窗口的末价除以首价再减1，形成跨231个交易日的强弱分数。按分数从高到低排序，同分按股票代码排序。

调仓时先留存质量池内的旧仓，再从当期前6名依次补足空位，目标持仓最多6只。

- 同一申万一级行业最多持有2只。 候选受行业上限或数据缺失限制时跳过，补位范围始终限定在前6名。

## 三、退出与再平衡

调仓时，持仓任何一项质量池条件确认不再满足，即计划清仓。

每轮执行开始时冻结单只目标市值：

单只目标市值 = 策略账户总权益 ÷ 6。调整数量按100股整手取整，不足一手不动。
