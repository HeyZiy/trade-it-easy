## 策略家族与不可混用的假设

| 策略类型          | 真正交易的对象        | 典型入场       | 主要失效模式           |
| ------------- | -------------- | ---------- | ---------------- |
| 指数/ETF 配置与再平衡 | 长期资产配置偏离       | 定期投入/阈值再平衡 | 全面熊市、估值长期偏高      |
| 行业横截面动量       | 行业相对强弱         | 排名靠前直接持有   | 主线退潮、动量崩溃        |
| 个股/指数突破追随     | 新高或平台突破后的扩散    | 突破确认       | 假突破、涨停/跳空造成不可控止损 |
| 价格循环波段        | 恐慌修复、延伸衰竭等状态转移 | 由完整阶段机定义   | 阶段误判、参数化主观性      |
| 均值回归          | 短期过度反应后的回补     | 极端乖离/超卖    | 单边趋势             |

## 候选研究池

| 候选            | 可能的收益来源   | 与现有策略的关系                  |
| ------------- | --------- | ------------------------- |
| ETF 网格/均值回归   | 震荡中的波动收敛  | 与动量的失效环境互补，但必须独立预算、独立处理破网 |
| 可转债双低轮动       | 债底保护与转股期权 | 可能提供不同风险来源；仍受开户条件与信用风险约束  |
| 小市值裸暴露        | 规模因子      | 风格崩塌风险与个人承受能力不匹配          |
| 期权卖方、期现/折溢价套利 | 权利金或速度优势  | 对保证金、交易基础设施和执行速度要求过高      |
| 业绩预告漂移等事件策略   | 信息反应不足    | 数据工程与事件处理成本高              |
